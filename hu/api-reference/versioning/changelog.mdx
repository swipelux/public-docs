Ez az oldal a Swipelux API dátumozott változásait sorolja fel. Minden bejegyzés jelzi az érintett verziót, a változás típusát, valamint a fejlesztőktől esetlegesen elvárt teendőket.

Egy meglévő integráció korábbi verzióról történő frissítéséhez lásd: [Migrálás v3-ra](/hu/api-reference/versioning/migrate-to-v3).

_A közelgő változások itt jelennek meg, mielőtt élesbe kerülnek._

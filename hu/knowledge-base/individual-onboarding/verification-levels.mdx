## KYC ellenőrzési szintek

A Swipelux három szabályzati szintű személyazonosság-ellenőrzést használ. Az alkalmazandó szint az ügyfél kockázatától, joghatóságától, elvárt tranzakciós volumenétől és szabályozási követelményektől függ.

<Warning>
  Ezek a szintek szabályzati besorolásokat írnak le, nem aktuális API enumokat.
  Az aktuális feladatok határozzák meg a követelményeket egy adott ügyfélhez.
</Warning>

## Simplified KYC

A Simplified KYC-t jóváhagyott alacsony kockázatú, alacsony értékű folyamatokhoz használják.

### Szükséges információk

- Keresztnév
- Vezetéknév
- Születési dátum

### Mikor használják

- A tranzakciós összegek az alkalmazandó simplified küszöbök alatt vannak
- Az ügyfél alacsony kockázatú joghatóságban van

## Standard KYC

A Standard KYC személyazonosságot ellenőriz kormányzati dokumentummal és szelfi vagy élőség-ellenőrzéssel.

### Szükséges dokumentumok

- Kormányzati azonosító
- Szelfi vagy élőség-ellenőrzés

### Elfogadott azonosító dokumentumok

- Útlevél
- Vezetői engedély
- Nemzeti azonosító kártya

## Enhanced KYC (fokozott átvilágítás)

Az Enhanced KYC cím- és pénzbizonyítékokat ad hozzá magasabb kockázatú forgatókönyvekhez.

### Szükséges dokumentumok

- Minden, ami a Standard KYC-hez szükséges
- Lakcímigazolás
- Pénzforrás-igazolás

### Enhanced KYC kiváltó okai

- A tranzakciós volumen meghaladja a standard küszöböket
- Magas kockázatú joghatóság
- A megfelelőségi csapat kockázatértékelés alapján jelezte
- Szabályozási követelmények

### Lakcímigazolási követelmények

| Dokumentumtípus | Követelmények |
| --- | --- |
| Bankszámlakivonat | Az elmúlt 90 napban kiállítva |
| Közüzemi számla | Villany, gáz, víz vagy internet; az elmúlt 90 napban kiállítva |
| Kormányzati levél | Adóértesítés vagy hivatalos levelezés, az elmúlt 90 napban kiállítva |

### Pénzforrás-igazolási követelmények

| Dokumentumtípus | Leírás |
| --- | --- |
| Bankszámlakivonatok | Legutóbbi kivonatok, amelyek elegendő egyenleget vagy jövedelmet mutatnak |
| Fizetési igazolások | Munkabér-jövedelem igazolás |
| Adóbevallások | Éves adódokumentáció |
| Befektetési kivonatok | Bróker- vagy nyugdíjszámla-kivonatok |

## Szabályzati szintek és aktuális feladatok

Az aktuális feladatrészlet marad a következő API művelet forrása. Első fél hosted munkamenetet biztosíthat, választ kérhet beküldésen keresztül, vagy dokumentumbizonyítékot kérhet.

Néhány fokozott felülvizsgálathoz a megfelelőségi csapat kapcsolatba léphet az ügyfél regisztrált e-mail címével. Ezt a kapcsolatot szabályzati felülvizsgálati koordinációként kezelje, nem az aktuális API-erőforrások olvasásának helyettesítőjeként.

Lásd [magánszemély onboarding](/hu/integration/onboarding/customers#individual-customers), [Képességek és feladatok](/hu/integration/onboarding/capabilities-and-requirements#complete-current-tasks) és [Integrációs dokumentumok útmutató](/hu/integration/onboarding/capabilities-and-requirements#upload-documents).

description: "Vezérelje a képesség-, feladat-, tárca- és átutalás-kimeneteket a Swipelux sandbox környezetben, miközben az integrációját építi és regressziós teszteli."
---

A sandbox ugyanazt az API-hosztot használja, mint az éles környezet. A sandbox API-kulcs kiválasztja a tesztkörnyezetet, ahol a segédeszközök valós pénzmozgás nélkül szimulálják a kimeneteket.

Tartsa a kulcsot a backendjén. A sandbox segédeszközök nem helyettesítik az éles megfelelőséget vagy onboardingot.

```bash
export API_BASE='https://platform.swipelux.com'
export SWIPELUX_SANDBOX_API_KEY='replace-with-your-sandbox-key'
```

## Képesség készenlétének tesztelése

Egy képesség kérése után állítsa be annak sandbox státuszát a [`POST /v3/sandbox/customers/{customerId}/capabilities/{capabilityId}/status`](/api-reference/sandbox/post-v3-sandbox-customers-by-customer-id-capabilities-by-capability-id-status) művelettel:

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/customers/${CUSTOMER_ID}/capabilities/${CAPABILITY_ID}/status" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"status":"ready"}'
```

A segédeszköz használata után frissítse le a képességet. Az aktuális `status` és `openTaskIds` értékeit tekintse annak az eredménynek, amelyet a terméknek kezelnie kell.

## Nyitott feladat tesztelése

Hozzon létre egy sandbox feladatot a [`POST /v3/sandbox/tasks`](/api-reference/sandbox/post-v3-sandbox-tasks) művelettel. Rendelje ahhoz az erőforráshoz, amelynek a munkafolyamatát teszteli, és az `items` mezőben írja le, mit kell beküldenie az ügyfélnek. Ez az útmutató capability- és transfer-munkafolyamatokat mutat be; az API Reference tartalmazza a customer scope-ot és a teljes kérési sémát.

Szöveges válaszhoz használjon `explanation`, fájlfeltöltéshez pedig `document` elemet. Az új `profile` elemekhez `profilePointer` is szükséges, amely az ügyfélmezőt megnevező JSON Pointer. A többi elemtípusért és mezőért lásd a [Sandbox feladat létrehozása](/api-reference/sandbox/post-v3-sandbox-tasks) oldalt.

A transfer-példához először hozzon létre sandbox transfert [pay-in](/hu/integration/receive-funds) vagy [payout](/hu/integration/send-funds) munkafolyamattal, majd exportálja a visszaadott `data.id` értéket:

```bash
export TRANSFER_ID='tr_replace_with_your_transfer_id'
```

<Tabs>
  <Tab title="Képesség + magyarázat">

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/tasks" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data @- <<JSON
{
  "scope": {
    "type": "capability",
    "customerId": "${CUSTOMER_ID}",
    "capabilityId": "${CAPABILITY_ID}"
  },
  "items": [
    {
      "type": "explanation",
      "request": "Explain the source of funds."
    }
  ]
}
JSON
```

  </Tab>
  <Tab title="Átutalási RFI + dokumentum">

Szűkítse a feladat scope-ját a felülvizsgálat alatt álló átutalásra, és kérjen egy dokumentumot olyan `constraints` beállításokkal, amelyek szűkítik az elfogadott típusokat, formátumokat és kort.

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/tasks" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data @- <<JSON
{
  "scope": {
    "type": "transfer",
    "customerId": "${CUSTOMER_ID}",
    "transferId": "${TRANSFER_ID}"
  },
  "category": "transaction_rfi",
  "items": [
    {
      "type": "document",
      "request": "Upload a bank statement showing the source of funds for this transfer.",
      "constraints": {
        "acceptedDocumentTypes": ["bank_statement"],
        "acceptedFormats": ["pdf", "jpeg"],
        "maxAgeDays": 90
      }
    }
  ]
}
JSON
```

A példa korlátozza az elfogadott dokumentumtípust, formátumot és kort. Az összes támogatott dokumentumkorlátozásért lásd a [Sandbox feladat létrehozása](/api-reference/sandbox/post-v3-sandbox-tasks) oldalt.

  </Tab>
</Tabs>

Tárolja a `data.id` értéket `TASK_ID`-ként, a `data.revision` értéket `TASK_REVISION`-ként, az aktuális `data.requirements[0].id` értéket pedig `REQUIREMENT_ID`-ként. A [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) hívásakor a válasz típusa egyezzen a létrehozott elemmel:

<Tabs>
  <Tab title="Magyarázati válasz">

```bash
curl --request POST \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/tasks/${TASK_ID}/submissions" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Idempotency-Key: sandbox-task-submission-001" \
  --header "Content-Type: application/json" \
  --data @- <<JSON
{
  "taskRevision": ${TASK_REVISION},
  "answers": [
    {
      "requirementId": "${REQUIREMENT_ID}",
      "answer": {
        "type": "text",
        "value": "Sandbox requirement completed."
      }
    }
  ]
}
JSON
```

  </Tab>
  <Tab title="Dokumentumválasz">

Töltsön fel egy megfelelő fájlt a [`POST /v3/customers/{customerId}/documents`](/api-reference/documents/post-v3-customers-by-customer-id-documents) művelettel, tárolja a visszaadott `data.id` értéket `DOCUMENT_ID`-ként, majd küldje be dokumentumválaszként:

```bash
curl --request POST \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/tasks/${TASK_ID}/submissions" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Idempotency-Key: sandbox-task-document-submission-001" \
  --header "Content-Type: application/json" \
  --data @- <<JSON
{
  "taskRevision": ${TASK_REVISION},
  "answers": [
    {
      "requirementId": "${REQUIREMENT_ID}",
      "answer": {
        "type": "document",
        "documentIds": ["${DOCUMENT_ID}"]
      }
    }
  ]
}
JSON
```

  </Tab>
</Tabs>

Ezután fogadja el vagy utasítsa el az aktuális beküldést a [`POST /v3/sandbox/tasks/{taskId}/review`](/api-reference/sandbox/post-v3-sandbox-tasks-by-task-id-review) művelettel:

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/tasks/${TASK_ID}/review" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"outcome":"accepted"}'
```

Használja a [Képességek és feladatok](/hu/integration/onboarding/capabilities-and-requirements) útmutatót az éles feladat-elvégzési mintához.

## Sandbox tárca feltöltése

Írjon jóvá egy kibocsátott tárcát a [`POST /v3/sandbox/accounts/{accountId}/topup`](/api-reference/sandbox/post-v3-sandbox-accounts-by-account-id-topup) művelettel:

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/accounts/${ACCOUNT_ID}/topup" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"amount":"250.00","currency":"USDC"}'
```

Tárolja a visszakapott `data.id` értéket `TRANSFER_ID`-ként, ha meg szeretné vizsgálni a szimulált feltöltési átutalást.

A feltöltés azonosítója egyben átutalás-azonosító is. Kérje le a [`GET /v3/transfers/{transferId}`](/api-reference/money-movement/get-v3-transfers-by-transfer-id) művelettel, vagy listázza a [`GET /v3/transfers`](/api-reference/money-movement/get-v3-transfers) művelettel, hogy a bejövő befizetési kódútvonalát sandbox feltöltésekkel gyakorolja. Az átutalás vetülete egy befejezett bejövő stablecoin befizetés `origin: "inbound_deposit"`, `method: "stablecoin_transfers"` és `direction: "stablecoin_move"` értékekkel, és az egyező `accountId`, `origin`, `method` és `direction` listaszűrők adják vissza.

## Átutalás befejezése vagy sikertelenné tétele

Állítsa be a kimenetet a [`POST /v3/sandbox/transfers/{transferId}/state`](/api-reference/sandbox/post-v3-sandbox-transfers-by-transfer-id-state) művelettel:

<Tabs>
  <Tab title="Befejezés">

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/transfers/${TRANSFER_ID}/state" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"state":"completed"}'
```

  </Tab>
  <Tab title="Sikertelen">

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/transfers/${TRANSFER_ID}/state" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data @- <<'JSON'
{
  "state": "failed",
  "stateDetail": {
    "code": "sandbox_review",
    "message": "Sandbox transfer failed."
  }
}
JSON
```

  </Tab>
</Tabs>

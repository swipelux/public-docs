title: "Hibák és újrapróbálkozások"
description: "Kezelje az összes nyilvános Swipelux API problémakódot, döntse el, mikor próbálkozzon újra, és oldja meg a validációs, állapot-, idempotencia- és platformhibákat."
---

A Swipelux API hibái az `application/problem+json` médiatípust használják. Ágaztassa el az alkalmazás viselkedését a stabil `code` érték alapján, majd használja az alábbi műveletet és útmutatót a hiba megoldásához.

| Mező | Hogyan használja |
| --- | --- |
| `type` | A problémakód stabil dokumentációs URI-ja. |
| `title` | Rövid, ember által olvasható problémacím. |
| `status` | A válaszhoz tartozó HTTP-státusz. |
| `code` | Stabil, géppel olvasható érték az alkalmazáslogikához. |
| `detail` | Kontextusfüggő, ember által olvasható szöveg ehhez az előforduláshoz. Ne elemezze és ne hasonlítsa össze. |
| `correlationId` | Kérésazonosító, amelyet tároljon a naplókban, és adjon meg a támogatással való kapcsolatfelvételkor. |
| `retryable` | Ha `true`, ugyanaz a kérés később sikerülhet. Ha `false`, változtassa meg a kérést, vagy teljesítsen egy előfeltételt, mielőtt újra próbálkozik. |
| `errors[]` | Mezőszintű validációs részletek, elérhetőség esetén JSON Pointerrel. |

Az idempotens írásokat az eredeti `Idempotency-Key` értékkel, valamint változatlan metódussal, útvonallal és törzzsel próbálja újra. Soha ne használja újra ezt a kulcsot egy másik szándékolt művelethez.

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**HTTP-státusz:** `403`<br />
**Újrapróbálható:** Nem<br />
**Problématípus:** `https://docs.swipelux.com/errors/forbidden`

**Jelentés:** Az API-kulcs érvényes, de nem jogosult a művelet végrehajtására.

**Mikor fordul elő:** A hitelesítő adat nem rendelkezik a szükséges jogosultsággal, vagy éles hitelesítő adat hív csak sandboxban elérhető végpontot.

**Teendő:** Használjon a megfelelő környezethez tartozó, szükséges jogosultságokkal rendelkező hitelesítő adatot. Ne tegye közzé és ne cserélje a kulcsokat kliensoldali kódban.

**Újrapróbálási útmutató:** Ne próbálja újra a változatlan kérést. Alkalmazza a fenti teendőt, mielőtt újabb kérést küld.

**Érintett API-műveletek:** Az összes hitelesített API-művelet.

### `invalid_field_for_type`

**HTTP-státusz:** `400`, `422`<br />
**Újrapróbálható:** Nem kerül visszaadásra<br />
**Problématípus:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**Jelentés:** A kérés olyan mezőket tartalmaz, amelyek nem érvényesek a kiválasztott erőforrástípushoz.

**Mikor fordul elő:** Egy diszkriminált kérés, például magánszemély–üzleti profil, másik variáns mezőit tartalmazza, vagy kihagyja a kiválasztott típusa által megkövetelt mezőket.

**Teendő:** Használja a kiválasztott típus sémáját, távolítsa el a más variánsokhoz tartozó mezőket, adja meg a kötelező mezőit, és küldjön javított kérést.

**Újrapróbálási útmutató:** Ez a probléma nem ad vissza `retryable` értéket. Ne feltételezze, hogy a változatlan újrapróbálkozás biztonságos; kövesse a fenti teendőt és a művelet idempotencia-követelményeit.

**Érintett API-műveletek:**

- [`POST /v3/customers`](/api-reference/customers/post-v3-customers) (`postV3Customers`, status `400`)
- [`PATCH /v3/customers/{customerId}`](/api-reference/customers/patch-v3-customers-by-customer-id) (`patchV3CustomersByCustomerId`, status `400`)
- [`POST /v3/customers/{customerId}/export`](/api-reference/customers/post-v3-customers-by-customer-id-export) (`postV3CustomersByCustomerIdExport`, status `422`)
- [`POST /v3/customers/{customerId}/related-parties`](/api-reference/customers/post-v3-customers-by-customer-id-related-parties) (`postV3CustomersByCustomerIdRelated-parties`, status `400`)
- [`PATCH /v3/customers/{customerId}/related-parties/{relatedPartyId}`](/api-reference/customers/patch-v3-customers-by-customer-id-related-parties-by-related-party-id) (`patchV3CustomersByCustomerIdRelated-partiesByRelatedPartyId`, status `400`)

### `request_body_too_large`

**HTTP-státusz:** `413`<br />
**Újrapróbálható:** Nem<br />
**Problématípus:** `https://docs.swipelux.com/errors/request-body-too-large`

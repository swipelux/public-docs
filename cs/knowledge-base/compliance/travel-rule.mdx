## Compliance Travel Rule

Swipelux uplatňuje kontroly FATF doporučení 16, když převody překračují platný lokální práh.

- **VASP-VASP:** Swipelux identifikuje protistranu VASP a přenáší data odesílatele/příjemce přes protokol (TRISA/Notabene)
- **Nehostované peněženky:**
  - (a) Swipelux shromažďuje požadované informace o odesílateli/příjemci
  - (b) Žádná data nejsou přenášena, protože neexistuje přijímající VASP
  - (c) Převody mohou být zablokovány, pokud blockchainová analytika indikuje vysoké riziko

Související API workflow: [příjemci](/cs/integration/recipients) a [odesílat prostředky](/cs/integration/send-funds).

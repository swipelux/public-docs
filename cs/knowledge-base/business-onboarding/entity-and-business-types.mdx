## Koncepty klasifikace subjektu a podnikání

Swipelux používá následující koncepty ke klasifikaci firmy během KYB přezkoumání.

<Warning>
  Tyto štítky jsou koncepty klasifikace politiky. Nejsou to aktuální
  enumy požadavků a nezaručují, že firma je způsobilá nebo schválená.
</Warning>

## Typy obchodních subjektů

| Typ subjektu | Popis |
| --- | --- |
| Limited Liability Company | LLC nebo ekvivalent |
| Corporation | Obecná korporace |
| S Corporation | US S corporation |
| C Corporation | US C corporation |
| Partnership | Obecné partnerství |
| Limited Partnership | Komanditní společnost |
| Sole Proprietorship | Individuálně vlastněná firma |
| Nonprofit | Nezisková organizace |
| Trust | Obchodní trust |
| Cooperative | Družstvo vlastněné členy |
| DAO | Decentralizovaná autonomní organizace |
| Foundation | Nadace |
| Other | Jiná forma subjektu |

## Jak tyto koncepty používat

Nepřekládejte tento katalog politiky na hodnoty požadavků. Aktuální požadavky úkolů určují hodnoty, popisy a důkazy, které za konkrétního zákazníka a capability odesíláte.

Před odpovědí přečtěte nejnovější úkol. Pro aktuální implementační model viz [Capabilities a úkoly](/cs/integration/onboarding/capabilities-and-requirements#complete-current-tasks) a pro nastavení zákazníka a souvisejících stran viz [onboarding firem](/cs/integration/onboarding/customers#business-customers).

description: "Zpracujte každý veřejný problem kód Swipelux API, rozhodněte, kdy opakovat, a vyřešte selhání validace, stavu, idempotence a platformy."

Chyby Swipelux API používají mediální typ `application/problem+json`. Větvete chování své aplikace podle stabilní hodnoty `code` a poté použijte operaci a pokyny níže k vyřešení selhání.

| Pole | Jak jej použít |
| --- | --- |
| `type` | Stabilní URI dokumentace pro kód problému. |
| `title` | Krátký lidsky čitelný název problému. |
| `status` | HTTP status přiřazený k této odpovědi. |
| `code` | Stabilní strojově čitelná hodnota pro aplikační logiku. |
| `detail` | Kontextový lidsky čitelný text pro tento konkrétní výskyt. Neparsujte jej ani neporovnávejte. |
| `correlationId` | Identifikátor požadavku, který uložte do logů a uveďte při kontaktování podpory. |
| `retryable` | Když je `true`, stejný požadavek může později uspět. Když je `false`, změňte požadavek nebo nejprve splňte předpoklad, než to zkusíte znovu. |
| `errors[]` | Detaily validace na úrovni polí, včetně JSON Pointeru, pokud je k dispozici. |

Idempotentní zápisy opakujte s původním `Idempotency-Key` a nezměněnou metodou, cestou a tělem. Nikdy nepoužívejte tento klíč znovu pro jinou zamýšlenou operaci.

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**Stav HTTP:** `403`<br />
**Opakovatelné:** Ne<br />
**Typ problému:** `https://docs.swipelux.com/errors/forbidden`

**Význam:** API klíč je platný, ale nemá oprávnění tuto operaci provést.

**Kdy nastává:** Přihlašovacím údajům chybí požadované oprávnění, nebo produkční přihlašovací údaje volají endpoint určený pouze pro sandbox.

**Co dělat:** Použijte přihlašovací údaje pro správné prostředí s požadovanými oprávněními. Nevystavujte ani nenahrazujte klíče v kódu na straně klienta.

**Pokyny k opakování:** Neopakujte nezměněný požadavek. Před odesláním dalšího požadavku proveďte akci uvedenou výše.

**Relevantní API operace:** Všechny autentizované API operace.

### `invalid_field_for_type`

**Stav HTTP:** `400`, `422`<br />
**Opakovatelné:** Nevrací se<br />
**Typ problému:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**Význam:** Požadavek obsahuje pole, která nejsou platná pro vybraný typ prostředku.

**Kdy nastává:** Diskriminovaný požadavek, například profil jednotlivce versus firmy, obsahuje pole z jiné varianty nebo vynechává pole vyžadovaná vybraným typem.

**Co dělat:** Použijte schéma vybraného typu, odstraňte pole patřící jiným variantám, doplňte jeho povinná pole a odešlete opravený požadavek.

**Pokyny k opakování:** Tento problém nevrací `retryable`. Nepředpokládejte, že nezměněné opakování je bezpečné; řiďte se akcí výše a požadavky operace na idempotenci.

**Relevantní API operace:**

- [`POST /v3/customers`](/api-reference/customers/post-v3-customers) (`postV3Customers`, status `400`)

- [`POST /v3/customers/{customerId}/export`](/api-reference/customers/post-v3-customers-by-customer-id-export) (`postV3CustomersByCustomerIdExport`, status `422`)
- [`POST /v3/customers/{customerId}/related-parties`](/api-reference/customers/post-v3-customers-by-customer-id-related-parties) (`postV3CustomersByCustomerIdRelated-parties`, status `400`)
- [`PATCH /v3/customers/{customerId}/related-parties/{relatedPartyId}`](/api-reference/customers/patch-v3-customers-by-customer-id-related-parties-by-related-party-id) (`patchV3CustomersByCustomerIdRelated-partiesByRelatedPartyId`, status `400`)

### `request_body_too_large`

**Stav HTTP:** `413`<br />
**Opakovatelné:** Ne<br />
**Typ problému:** `https://docs.swipelux.com/errors/request-body-too-large`

**Význam:** Tělo požadavku překračuje velikost přijímanou operací.

**Kdy nastává:** Odeslání úkolu posílá více dat požadavku, než kolik API dokáže zpracovat v jednom těle.

**Co dělat:** Odstraňte nepotřebná data, místo vkládání obsahu souborů použijte odkazy na dokumenty a odešlete menší odeslání, které stále odpovídá na aktuální požadavky.

**Pokyny k opakování:** Neopakujte nezměněný požadavek. Před odesláním dalšího požadavku proveďte akci uvedenou výše.

**Relevantní API operace:**

- [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) (`createCustomerTaskSubmission`, status `413`)

**Opakovatelné:** Ne<br />

**Pokyny k opakování:** Neopakujte nezměněný požadavek. Před odesláním dalšího požadavku proveďte akci uvedenou výše.

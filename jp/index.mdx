Swipelux API を利用して、顧客オンボーディングとグローバルな資金移動を構築できます。

<Columns cols={3}>
  <Card title="インテグレーションを始める" icon="rocket" href="/jp/integration/quickstart">
    サンドボックスで顧客を作成し、最初の資金フローを実行します。
  </Card>
  <Card title="API を探索する" icon="code" href="/jp/api-reference/introduction">
    正確な操作、リクエストフィールド、レスポンススキーマを確認します。
  </Card>
  <Card title="コンプライアンスとオンボーディング" icon="shield-check" href="/jp/knowledge-base/compliance/overview">
    利用可能地域、コンプライアンスポリシー、オンボーディング要件を確認します。
  </Card>
</Columns>

## 構築できるもの

<CardGroup cols={3}>
  <Card title="資金を受け取る" icon="arrow-down-to-line" href="/jp/integration/receive-funds">
    フィアットを受け入れ、ステーブルコインを顧客ウォレットに決済します。
  </Card>
  <Card title="資金を送る" icon="arrow-up-from-line" href="/jp/integration/send-funds">
    顧客所有の口座やサードパーティの送金先へ支払います。
  </Card>
  <Card title="銀行口座を発行する" icon="building-columns" href="/jp/integration/issue-bank-account">
    ウォレットへ決済される再利用可能な銀行口座情報を顧客に提供します。
  </Card>
</CardGroup>

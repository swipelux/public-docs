## 2026-08-17

**バージョン:** v3

### 追加
- OpenAPI 仕様に v3 Problem Details カタログを公開しました。これにより、インテグレーターはスキーマから直接エラー応答をマッピングできます。
- v3 の口座 webhook イベントに `customerId` を追加し、追加の読み取りなしに口座アクティビティを所有者の顧客に関連付けられるようにしました。[Webhook](/jp/integration/webhooks) を参照してください。
- マーチャントパネルで V3 個人プロファイルフィールドを全面的にカバーし、オンボーディング担当者が v3 API 経由で収集されたすべての KYC フィールドを確認・編集できるようになりました。[顧客のオンボーディング](/jp/integration/onboarding/customers) を参照してください。
- v1/v2 → v3 の開発者向け移行ガイドを公開しました。[v3 への移行](/jp/api-reference/versioning/migrate-to-v3) を参照してください。

### 変更
- 顧客および口座の国コードは、書き込み時に割り当て済みの ISO 3166-1 alpha-2 値として検証されるようになりました。読み取りはレガシーの保存値を許容するため、既存のレコードは引き続き解決されます。[口座とウォレット](/jp/integration/accounts) を参照してください。
- BlindPay の USDC 提供は宛先ネットワークによってスコープが限定されるようになりました。これにより、見積もりと送金は宛先が実際にサポートするネットワーク上でのみ USDC を提供します。
- すべてのレール取り込みで Swipelux の Terms of Service が必要になり、ACH 取り込みでは最初のステップから ToS が含まれるようになりました。プロバイダのレビュー中も既存のセッションは再開可能なままです。[顧客のオンボーディング](/jp/integration/onboarding/customers) を参照してください。
- `Capability.ready` は口座発行を意味しなくなりました。口座イベントを待つ (または口座を読み取る) までは、口座の存在を仮定しないでください。[ケイパビリティとタスク](/jp/integration/onboarding/capabilities-and-requirements) を参照してください。
- iPhone からの HEIC アップロードが本人確認および住所確認書類として受け入れられるようになりました。

### 修正
- 使用済みの見積もりを再実行すると、汎用エラーではなく `409 quote_execution_consumed` を返すようになりました。[見積もりと送金](/jp/integration/quotes-and-transfers) を参照してください。
- 大量の履歴結果に対する送金一覧の読み取りおよび見積もり金額の読み取りが 500 を返さなくなりました。
- 競合する KYC リダイレクトは、404 ではなく競合を返すようになり、リトライがクリーンに解決するようになりました。ホスト型 Align リダイレクトが途中でロールバックしなくなり、process-KYC リンクはプロバイダのレビュー中も再開可能なままです。
- 個人顧客の関係者読み取りが 404 を返さなくなりました。
- 外部 ACH 口座のインポートで拒否が発生した場合、プロバイダが報告した原因が表示されるようになり、担当者が実際の理由に基づいて対応できるようになりました。[口座とウォレット](/jp/integration/accounts) を参照してください。
- 標準承認スイープが自身のキュー先頭で停止しなくなり、オンボーディングの判断が担当者の介入なしにレビューを進められるようになりました。
- サンドボックスの Align 顧客がエンドツーエンドでプロビジョニングされるようになり、自己作成した送金がサンドボックスで競合として報告されなくなりました。
- ウォレット無効フィールドを含む KYB 提出は送信前に拒否されるようになり、プロバイダ同期の失敗がマーチャントパネルで成功として報告されなくなりました。
- マーチャントパネルの RFI (情報要求) タスク: 送信された回答が完了として表示されるようになり、規約アクションが他のステップとは別に追跡され、重複した文書テキストが削除され、開始済みの KYC セッションは申請者が完了するまで保留のままとなり、古い RFI タスクが要件ビューを壊さなくなりました。
- マーチャントパネルの検証リンク行に、すべての行で **Open** アクションが表示されるようになり、ウォレットインフラストラクチャのすべてのタスクリンクが要件ビューにレンダリングされるようになりました。

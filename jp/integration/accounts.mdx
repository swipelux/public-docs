title: "口座とウォレット"

---

すべての口座は 1 人の顧客に属します。管理者と、それがウォレットか銀行口座かの 2 つの軸で選択してください。

顧客口座の一覧、作成、取得、更新、アーカイブ操作は `/v3/customers/{customerId}/accounts` 配下にあり、個別口座の操作では `/{accountId}` を追加します。`accountId` から `customerId` を逆引きする方法はありません。後続のリクエストで口座を指定できるよう、各 `accountId` と対応する `customerId` を保存してください。

## 口座を選択する

| 口座 | 用途 |
| --- | --- |
| 発行済みウォレット | 保管型のステーブルコイン残高を保持する、支払いに資金を用意する、入金を受ける、または発行済み銀行口座の決済先として使用します。 |
| 発行済み銀行口座 | 発行ウォレットに決済される再利用可能な銀行情報を顧客に提供します。 |
| 外部ウォレット | 顧客が所有するブロックチェーンアドレスを記録します。 |
| 外部銀行口座 | ファーストパーティ支払いのために、顧客が所有する銀行口座を記録します。 |

`issued` は Swipelux がリソースを作成し管理することを意味します。`external` は顧客が所有するエンドポイントを記録します。サードパーティのエンドポイントは、顧客の口座リストではなく [受取人と送金先](/jp/integration/recipients) に属します。

カードまたは Apple Pay 向けのマーチャントパネルの **First pay-in** ガイドを開始する前に、その顧客に Polygon ウォレットを作成してください。ガイドではその Polygon ウォレットのみが提示され、ウォレットがなければ続行できません。この前提条件はマーチャントパネルのガイドに適用されます。API を直接統合する場合は、現在の顧客とケイパビリティに対して返された通貨、ネットワーク、メソッド、口座タイプのみを使用してください。

## 口座を作成する {#create-the-account}

[`POST /v3/customers/{customerId}/accounts`](/api-reference/accounts/post-v3-customers-by-customer-id-accounts) を使用します。以下のいずれかのリクエストボディとともに、次のヘッダーを送信します。

```http
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: account-create-001
Content-Type: application/json
```

  "currency": "USDC",

現在の顧客とケイパビリティに対して返された通貨、ネットワーク、方法、口座タイプのみを使用してください。他の顧客や環境から利用可能性をコピーしないでください。

## 口座が利用可能になるまで待つ

作成レスポンスの `data.id`、`data.status`、`data.openTaskIds` を保存します。送金を見積もったり銀行情報を表示したりする前に、[`GET /v3/customers/{customerId}/accounts/{accountId}`](/api-reference/accounts/get-v3-customers-by-customer-id-accounts-by-account-id) で最新の口座を読み取ってください。

現在のステータスが次の操作を許可する場合にのみ口座を使用してください。タスク ID がオープンの場合は、[ケイパビリティとタスク](/jp/integration/onboarding/capabilities-and-requirements) を通じて完了してください。

発行済み銀行口座は、プロビジョニング中に `details: null` を返す場合があります。最新の読み取りで完全な情報セットが返されてから、銀行情報を提示してください。`details.referenceRequired` が true の場合は、`details.reference` を銀行座標とともに正確に表示してください。

## 口座の役割を明確に保つ

支払いにおいて、発行ウォレットは `in.accountId` の送金元となります。顧客所有の銀行口座は `destinationId` です。発行済み銀行口座では、`settlement.accountId` は一致した入金を受け取る発行ウォレットです。

次に、ready 状態の口座を [資金を受け取る](/jp/integration/receive-funds)、[資金を送る](/jp/integration/send-funds)、または [銀行口座を発行する](/jp/integration/issue-bank-account) で使用してください。

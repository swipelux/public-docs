## スクリーニングとモニタリング

Swipelux は、顧客、ウォレット、およびトランザクションにわたって継続的な AML/CTF モニタリングを実施します。

- **制裁/PEP:** サインアップやプロファイル変更を含む、日次およびイベントトリガーのスクリーニング
- **ブロックチェーン分析:** ミキサー、ダークネットマーケット、および制裁対象事業体への露出について、入金および出金のスクリーニング
- **トランザクションモニタリング:** ストラクチャリング、速度の異常、および不正パターンのリアルタイム検出
- **ケースエスカレーション:** 高リスクアラートは手動レビューを経て、SAR/ISR 提出に至る場合があります

関連 API ワークフロー: [個人オンボーディング](/jp/integration/onboarding/customers#individual-customers) および [ビジネスオンボーディング](/jp/integration/onboarding/customers#business-customers)。

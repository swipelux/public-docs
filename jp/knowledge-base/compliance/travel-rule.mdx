## Travel Rule コンプライアンス

Swipelux は、送金が該当するローカルしきい値を超えた場合に FATF 勧告 16 の制御を適用します。

- **VASP 間:** Swipelux はカウンターパーティ VASP を識別し、プロトコル (TRISA/Notabene) 経由で送金人/受取人データを送信します
- **Unhosted ウォレット:**
  - (a) Swipelux は必要な送金人/受取人情報を収集します
  - (b) 受信 VASP が存在しないため、データは送信されません
  - (c) ブロックチェーン分析が高リスクの露出を示す場合、送金がブロックされる場合があります

関連 API ワークフロー: [受取人](/jp/integration/recipients) および [資金を送る](/jp/integration/send-funds)。

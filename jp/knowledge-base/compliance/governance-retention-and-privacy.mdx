## ガバナンスと役割

### 責任マトリクス

| 責任 | Swipelux (VASP) | サブマーチャント |
| --- | --- | --- |
| 暗号資産の保管 | 責任あり | 許可されない |
| ブロックチェーン実行 | 責任あり | 許可されない |
| ユーザー検証 (KYC) | 責任あり(直接または reliance) | UX の引き継ぎに責任あり |
| 制裁スクリーニング | 責任あり(全ユーザー) | 自社スタッフに責任あり |
| ジオブロッキング | IP/KYC で強制 | UI レベルで実装が必要 |
| ライセンシング | VASP ライセンスのみ | セクターライセンス(例: ゲーミング) |

### 責任マトリクス

- **Swipelux:** 保管、ブロックチェーン実行、KYC/KYB、モニタリング、Travel Rule、制裁
- **サブマーチャント:** ユーザージャーニー設計、ジオブロッキング、業種別ライセンシング、マーケティングコンプライアンス、望まない米国ターゲティングの防止

Swipelux は、フロー内における規制対象の暗号資産カストディアンです。サブマーチャントは、ユーザーの資産や秘密鍵を保持、制御、またはアクセスすることは一切ありません。

関連 API ワークフロー: [個人オンボーディング](/jp/integration/onboarding/customers#individual-customers) および [ビジネスオンボーディング](/jp/integration/onboarding/customers#business-customers)。

## 監査可能性と保持

Swipelux は、EU の AML 法およびエストニアの MLTFPA に基づき、ユーザーの本人確認および取引データを 5 年間保持します。

データ主体の削除要求は、AML により義務付けられた記録には適用されません。

Swipelux は、GDPR に準拠した EU 内のコンプライアントなインフラストラクチャにすべてのデータを保存します。

## 支払い方法

Swipelux は、入金と支払いのために複数の決済レールをオーケストレーションします。

### サポートされている入金方法

1. **フィアット入金 (User -> Swipelux)**
   - Open Banking: Instant SEPA / Faster Payments
   - カードアクワイアリング: Visa/Mastercard (MCC 制限の対象)

2. **暗号資産入金 (User -> Swipelux)**
   - ユーザーは、USDC などのサポートされている資産を、自身の分離された MPC ウォレットに直接入金できます。ウォレットは第三者サービスプロバイダーによってスクリーニングされます。

3. **サードパーティアグリゲーター**
   - Swipelux は、ライセンスを取得したサードパーティパートナーからのオーケストレーションされた決済をサポートします。これらのフローにおいて、Swipelux はウォレットプロバイダーおよび最終決済エージェントとして機能します。

実装ガイダンスについては、[資金を受け取る](/jp/integration/receive-funds) をご覧ください。

### サポートされている支払い方法

**フィアット支払い (Swipelux -> User)**

- **フロー:** Stablecoin -> Swipelux Liquidity -> Fiat Conversion -> User Bank Account
- **ルール:** 支払いは、検証済み KYC ユーザーの正確な法的名義の銀行口座にのみ送信できます。このフローでは、サードパーティ支払いはサポートされません。

上記の正確な名義の制限は、この直接ユーザー銀行支払いフローに適用されます。[受取人](/jp/integration/recipients) で説明されている個別の v3 recipient-destination フローを置き換えるものではありません。

実装ガイダンスについては、[資金を送る](/jp/integration/send-funds) をご覧ください。

## トランザクション上限

Swipelux は、顧客タイプ、検証レベル、およびリスクレビューに基づいてトランザクション上限を適用します。上限は、リスク情報の変化に応じて変更される場合があります。

### 個人顧客

| 上限タイプ | KYC Standard | KYC Enhanced |
| --- | --- | --- |
| 取引あたり | $10,000 | $50,000 |
| 日次 | $50,000 | $100,000 |
| 月次 | $100,000 | $250,000 |

### ビジネス顧客

| 上限タイプ | 金額 |
| --- | --- |
| 取引あたり | $30,000 |
| 日次 | $100,000 |
| 月次 | $500,000 |

### 備考

上限は、当社の AML ポリシーに従い、リスクスコアリングに基づいて調整される場合があります。上限に影響し得る要因には次が含まれます。

- 取引履歴とパターン
- 地理的な考慮事項
- 事業タイプと業種
- 全体的なリスク評価

特定の上限や上限の調整に関する質問については、コンプライアンスチームにお問い合わせください。

実装ガイダンスについては、[個人オンボーディング](/jp/integration/onboarding/customers#individual-customers) および [ビジネスオンボーディング](/jp/integration/onboarding/customers#business-customers) をご覧ください。

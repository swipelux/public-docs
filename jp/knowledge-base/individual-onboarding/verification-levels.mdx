## KYC 検証レベル

Swipelux は、身分検証の 3 つのポリシー階層を使用します。該当する階層は、顧客のリスク、管轄区域、想定取引量、および規制要件によって異なります。

<Warning>
  これらの階層は、現在の API enum ではなくポリシー分類を説明します。
  特定の顧客に対する要件は、現在のタスクが決定します。
</Warning>

## Simplified KYC

Simplified KYC は、承認された低リスク、低額のフローに使用されます。

### 必要情報

- 名
- 姓
- 生年月日

### 使用される場合

- 取引金額が該当する Simplified しきい値未満
- 顧客が低リスクの管轄区域にいる

## Standard KYC

Standard KYC は、政府発行ドキュメントと自撮りまたは liveness チェックで身分を検証します。

### 必要ドキュメント

- 政府発行 ID
- 自撮りまたは liveness チェック

### 受理される ID ドキュメント

- パスポート
- 運転免許証
- 国民 ID カード

## Enhanced KYC(強化デューデリジェンス)

Enhanced KYC は、より高リスクのシナリオに対して住所と資金の証拠を追加します。

### 必要ドキュメント

- Standard KYC で必要なすべて
- 住所証明
- 資金証明

### Enhanced KYC のトリガー

- 取引量が標準しきい値を超える
- 高リスクの管轄区域
- リスク評価に基づくコンプライアンスチームのフラグ
- 規制要件

### 住所証明の要件

| ドキュメントタイプ | 要件 |
| --- | --- |
| Bank statement | 過去 90 日以内の発行 |
| Utility bill | 電気、ガス、水道、またはインターネット。過去 90 日以内の発行 |
| Government-issued letter | 税務通知または公式通信で過去 90 日以内の発行 |

### 資金証明の要件

| ドキュメントタイプ | 説明 |
| --- | --- |
| Bank statements | 十分な残高または収入を示す最近の明細書 |
| Pay stubs | 雇用収入の検証 |
| Tax returns | 年次の税務書類 |
| Investment statements | 証券会社または退職口座の明細書 |

## ポリシー階層と現在のタスク

現在のタスクの詳細は、次の API アクションの信頼できる情報源であり続けます。ファーストパーティのホスト型セッションを提供する場合、送信を通じて回答を要求する場合、またはドキュメント証拠を要求する場合があります。

一部の enhanced レビューでは、コンプライアンスチームが顧客の登録メールアドレスに連絡することもあります。その連絡は、ポリシーレビュー調整として扱い、現在の API リソースを読み取ることの代替と考えないでください。

## 事業体および事業分類の概念

Swipelux は、KYB レビュー中にビジネスを分類するために次の概念を使用します。

<Warning>
  これらのラベルはポリシー分類の概念です。現在のリクエスト enum ではなく、
  ビジネスが適格または承認されることを保証するものではありません。
</Warning>

## ビジネス事業体タイプ

| 事業体タイプ | 説明 |
| --- | --- |
| Limited Liability Company | LLC または同等 |
| Corporation | 一般的な株式会社 |
| S Corporation | 米国 S コーポレーション |
| C Corporation | 米国 C コーポレーション |
| Partnership | 一般的なパートナーシップ |
| Limited Partnership | 有限責任パートナーシップ |
| Sole Proprietorship | 個人事業 |
| Nonprofit | 非営利組織 |
| Trust | ビジネストラスト |
| Cooperative | メンバー所有の協同組合 |
| DAO | 分散型自律組織 |
| Foundation | 財団事業体 |
| Other | その他の事業体形態 |

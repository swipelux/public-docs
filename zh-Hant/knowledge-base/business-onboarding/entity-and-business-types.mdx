## 實體與業務分類概念

Swipelux 在 KYB 審查期間使用下列概念對企業進行分類。

<Warning>
  這些標籤是政策分類概念,並非當前的請求枚舉值,也不保證企業具備
  資格或已獲得核准。
</Warning>

## 企業實體類型

| 實體類型 | 說明 |
| --- | --- |
| Limited Liability Company | LLC 或等同組織 |
| Corporation | 一般公司 |
| S Corporation | 美國 S 公司 |
| C Corporation | 美國 C 公司 |
| Partnership | 一般合夥 |
| Limited Partnership | 有限合夥 |
| Sole Proprietorship | 個人獨資 |
| Nonprofit | 非營利組織 |
| Trust | 商業信託 |
| Cooperative | 會員所有的合作社 |
| DAO | 去中心化自治組織 |
| Foundation | 基金會實體 |
| Other | 其他實體形式 |

## 如何使用這些概念

請勿將此政策目錄轉換為請求值。當前的任務要求決定您針對特定客戶與能力所提交的值、描述與佐證。

請於回應前讀取最新任務。當前的實作模型請參閱[能力與任務](/zh-Hant/integration/onboarding/capabilities-and-requirements#complete-current-tasks),客戶與關係人設定則請參閱[企業入駐](/zh-Hant/integration/onboarding/customers#business-customers)。

## 支付方式

Swipelux 為入金與出金整合多種結算通道。

### 支援的入金方式

1. **法幣入金(使用者 -> Swipelux)**
   - Open Banking:即時 SEPA / Faster Payments
   - 卡片收單:Visa/Mastercard(受 MCC 限制)

2. **加密資產入金(使用者 -> Swipelux)**
   - 使用者可將支援的資產(例如 USDC)直接存入其隔離式 MPC 錢包。錢包會由第三方服務供應商進行篩查。

3. **第三方整合商**
   - Swipelux 支援來自持照第三方合作夥伴的整合結算。Swipelux 在這些流程中作為錢包供應商與最終結算代理。

實作指引請參閱[接收資金](/zh-Hant/integration/receive-funds)。

### 支援的出金方式

**法幣出金(Swipelux -> 使用者)**

- **流程:** 穩定幣 -> Swipelux 流動性 -> 法幣兌換 -> 使用者銀行帳戶
- **規則:** 出金僅能發送至與已通過 KYC 驗證的使用者法定姓名完全相符的銀行帳戶。此流程不支援第三方出金。

上述精確姓名限制適用於此直接對使用者的銀行出金流程。它不會取代[收款人](/zh-Hant/integration/recipients) 中所描述的獨立 v3 收款人—目的地流程。

實作指引請參閱[發送資金](/zh-Hant/integration/send-funds)。

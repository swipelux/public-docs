## 交易限額

Swipelux 依客戶類型、驗證等級與風險審查適用交易限額。限額可能隨風險資訊變化而調整。

### 個人客戶

| 限額類型 | KYC 標準 | KYC 加強 |
| --- | --- | --- |
| 單筆交易 | $10,000 | $50,000 |
| 每日 | $50,000 | $100,000 |
| 每月 | $100,000 | $250,000 |

### 企業客戶

| 限額類型 | 金額 |
| --- | --- |
| 單筆交易 | $30,000 |
| 每日 | $100,000 |
| 每月 | $500,000 |

### 備註

限額可能依我們的 AML 政策進行風險評分調整。可能影響限額的因素包括:

- 交易歷史與模式
- 地理相關因素
- 業務類型與產業
- 整體風險評估

若對特定限額或限額調整有疑問,請聯繫法遵團隊。

實作指引請參閱[個人入駐](/zh-Hant/integration/onboarding/customers#individual-customers) 與[企業入駐](/zh-Hant/integration/onboarding/customers#business-customers)。

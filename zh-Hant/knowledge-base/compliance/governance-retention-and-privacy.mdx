## 治理與角色

### 責任矩陣

| 責任 | Swipelux(VASP) | 子商戶 |
| --- | --- | --- |
| 加密資產托管 | 負責 | 不允許 |
| 鏈上執行 | 負責 | 不允許 |
| 使用者驗證(KYC) | 負責(直接或信賴) | 負責 UX 交付 |
| 制裁篩查 | 負責(所有使用者) | 負責自身員工 |
| 地區封鎖 | 透過 IP/KYC 執行 | 必須在 UI 層級實作 |
| 執照 | 僅 VASP 執照 | 產業別執照(例如博弈) |

### 責任分工矩陣

- **Swipelux:** 托管、鏈上執行、KYC/KYB、監控、Travel Rule、制裁
- **子商戶:** 使用者旅程設計、地區封鎖、垂直產業執照、行銷合規、防止對美國進行未經邀約的行銷

Swipelux 是流程中受監理的加密資產托管人。子商戶絕不持有、控制或存取使用者資產或私鑰。

相關 API 工作流程:[個人入駐](/zh-Hant/integration/onboarding/customers#individual-customers) 與[企業入駐](/zh-Hant/integration/onboarding/customers#business-customers)。

## 可稽核性與保存

Swipelux 依歐盟 AML 法律及愛沙尼亞 MLTFPA 的要求,保存使用者身分與交易資料 5 年。

資料主體的刪除請求不適用於 AML 法定要求的紀錄。

Swipelux 所有資料皆存放於符合 GDPR 的合規歐盟基礎設施中。

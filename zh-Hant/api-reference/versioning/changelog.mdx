## 2026-08-17

**版本:** v3

### 新增
- 在 OpenAPI 規範中發布 v3 Problem Details 目錄,讓整合方可以直接從 schema 對應錯誤回應。 [Errors](/integration/errors).
- 為 v3 帳戶 webhook 事件新增 `customerId`,讓您無需後續讀取即可將帳戶活動關聯至擁有的客戶。請參閱 [Webhook](/zh-Hant/integration/webhooks)。
- 商家後台完整支援 V3 個人檔案欄位,讓入駐操作人員可以審核並編輯透過 v3 API 收集的每個 KYC 欄位。請參閱[客戶入駐](/zh-Hant/integration/onboarding/customers)。
- 發布 v3 開發者遷移指南。請參閱[遷移至 v3](/zh-Hant/api-reference/versioning/migrate-to-v3)。

### 變更
- 客戶與帳戶的國家代碼在寫入時現在會驗證為已指派的 ISO 3166-1 alpha-2 值。讀取時容許舊有儲存值,讓現有紀錄仍可繼續解析。請參閱[帳戶與錢包](/zh-Hant/integration/accounts)。
- USDC 的可用性現在依目的地網路限定,因此報價與轉帳只會在目的地實際支援的網路上提供 USDC。
- `Capability.ready` 表示權限已獲核准，並不表示帳戶已核發。請使用 `accountProvisioning` 追蹤帳戶核發狀態：`not_applicable`、`not_started`、`in_progress`、`issued` 或 `failed`。
- 現在接受來自 iPhone 的 HEIC 上傳作為身分與地址文件。

### 修正
- 重新執行已消耗的報價現在會回傳 `409 quote_execution_consumed`,而非通用錯誤。請參閱[報價與轉帳](/zh-Hant/integration/quotes-and-transfers)。
- 轉帳清單讀取與報價金額讀取在大量歷史結果上不再回傳 `500`。
- 個人客戶的關聯方讀取不再回傳 `404`。
- 商家後台中的驗證連結列現在每一列都會顯示 **Open** 動作,且每個錢包基礎設施任務連結都會在需求視圖中呈現。

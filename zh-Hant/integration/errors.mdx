Swipelux API 錯誤使用 `application/problem+json` 媒體類型。請依穩定的 `code` 值分支您的應用程式行為,然後使用下方的操作與指引解決失敗。

| 欄位 | 使用方式 |
| --- | --- |
| `type` | 問題代碼的穩定文件 URI。 |
| `title` | 簡短且人類可讀的問題標題。 |
| `status` | 與此回應相關聯的 HTTP 狀態。 |
| `code` | 供應用程式邏輯使用的穩定機器可讀值。 |
| `detail` | 此次發生時的情境化人類可讀文字。請勿解析或比較它。 |
| `correlationId` | 請求識別碼,請儲存在日誌中,並在聯絡支援時附上。 |
| `retryable` | 為 `true` 時,相同請求之後可能成功。為 `false` 時,請先變更請求或滿足前置條件,再重新嘗試。 |
| `errors[]` | 欄位層級的驗證詳細資訊,可用時包含 JSON Pointer。 |

重試冪等寫入時,請使用原始 `Idempotency-Key` 以及未變更的方法、路徑與主體。切勿將該金鑰重複用於不同的預期操作。

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**HTTP 狀態:** `403`<br />
**是否可重試:** 否<br />
**問題類型:** `https://docs.swipelux.com/errors/forbidden`

**含義:** API 金鑰有效,但不被允許執行此操作。

**發生時機:** 憑證缺少所需的權限,或正式環境憑證呼叫了僅限沙箱的端點。

**處理方式:** 請使用具備所需權限、對應正確環境的憑證。請勿在用戶端程式碼中暴露或替換金鑰。

**重試指引:** 請勿原樣重試該請求。請先採取上述行動,再傳送另一個請求。

**相關 API 操作:** 所有需要身分驗證的 API 操作。

### `invalid_field_for_type`

**HTTP 狀態:** `400`, `422`<br />
**是否可重試:** 不回傳<br />
**問題類型:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**含義:** 該請求包含對所選資源類型無效的欄位。

**發生時機:** 具區分類型的請求(例如個人與企業的個人資料)包含另一變體的欄位,或遺漏其所選類型必需的欄位。

**處理方式:** 請使用所選類型的 schema,移除屬於其他變體的欄位,提供其必填欄位,然後傳送更正後的請求。

**重試指引:** 此問題不會回傳 `retryable`。請勿假設原樣重試是安全的;請遵循上述行動及該操作的冪等性要求。

**相關 API 操作:**

### `request_body_too_large`

**HTTP 狀態:** `413`<br />
**是否可重試:** 否<br />
**問題類型:** `https://docs.swipelux.com/errors/request-body-too-large`

**含義:** 請求主體超過該操作可接受的大小。

**發生時機:** 任務提交傳送的請求資料超過 API 可在單一主體中處理的量。

**處理方式:** 請移除不必要的資料,使用文件參照而非內嵌檔案內容,並傳送仍能答覆當前要求的較小提交。

**重試指引:** 請勿原樣重試該請求。請先採取上述行動,再傳送另一個請求。

- [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) (`createCustomerTaskSubmission`, status `413`)

**問題類型:** `https://docs.swipelux.com/errors/unauthorized`

**重試指引:** 請勿原樣重試該請求。請先採取上述行動,再傳送另一個請求。

**問題類型:** `https://docs.swipelux.com/errors/unknown-parameter`

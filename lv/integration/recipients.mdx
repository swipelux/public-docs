---

Izmantojiet klienta kontu, ja klients ir galapunkta īpašnieks. Izmantojiet saņēmēju un galamērķi, ja līdzekļus saņem cita persona vai uzņēmums.

Saņēmējs reģistrē, kurš saņem līdzekļus. Galamērķis reģistrē, kur viņš tos saņem.

## 1. Izveidojiet saņēmēju

Izveidojiet privātpersonu vai uzņēmumu ar [`POST /v3/customers/{customerId}/recipients`](/api-reference/recipients/post-v3-customers-by-customer-id-recipients). Nosūtiet šīs galvenes:

```http
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: recipient-create-001
Content-Type: application/json
```

```json
{
  "type": "individual",
  "relationship": "contractor",
  "firstName": "Jason",
  "lastName": "Swipelux",
  "email": "jason@swipelux.com",
  "phone": "+14155551234",
  "address": {
    "streetLine1": "1 Market Street",
    "city": "San Francisco",
    "state": "CA",
    "postalCode": "94105",
    "country": "US"
  },
  "label": "Jason contractor"
}
```

`relationship` apraksta saņēmēja saistību ar jūsu klientu. Izvēlieties vērtību no [`POST /v3/customers/{customerId}/recipients` pieprasījuma shēmas](/api-reference/recipients/post-v3-customers-by-customer-id-recipients). Ja sūtāt `other`, nepievienojiet brīvā teksta lauku; shēma noraida nezināmus laukus.

Pirms fiat galamērķa izveides iekļaujiet adresi. Saglabājiet atgriezto saņēmēja `data.id` kā `RECIPIENT_ID` un saglabājiet tā pašreizējo statusu.

## 2. Pievienojiet galamērķi

Izveidojiet galapunktu ar [`POST /v3/customers/{customerId}/recipients/{recipientId}/destinations`](/api-reference/recipients/post-v3-customers-by-customer-id-recipients-by-recipient-id-destinations). Izmantojiet jaunu atslēgu šim paredzētajam galamērķim:

```http
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: recipient-destination-create-001
Content-Type: application/json
```

<Tabs>
  <Tab title="Bankas galamērķis">

```json
{
  "type": "ach",
  "currency": "USD",
  "details": {
    "routingNumber": "021000021",
    "accountNumber": "123456789",
    "accountType": "checking",
    "bankName": "Example Bank",
    "accountHolderName": "Jason Swipelux",
    "country": "US"
  }
}
```

  </Tab>
  <Tab title="Maka galamērķis">

```json
{
  "type": "wallet",
  "currency": "USDC",
  "ownership": {
    "type": "self_custodied"
  },
  "details": {
    "network": "base",
    "address": "0x1111111111111111111111111111111111111111"
  }
}
```

  </Tab>
</Tabs>

Izmantojiet `self_custodied` tikai tad, kad saņēmējs kontrolē maku. Ja maku tur cits kastodijs, sekojiet pašreizējam API atsauces variantam.

Saglabājiet atgriezto galamērķa `data.id` kā `DESTINATION_ID` un saglabājiet tā pašreizējo statusu.

## 3. Gaidiet galamērķa gatavību

Pirms kotācijas izveides nolasiet [`GET /v3/customers/{customerId}/recipients/{recipientId}/destinations/{destinationId}`](/api-reference/recipients/get-v3-customers-by-customer-id-recipients-by-recipient-id-destinations-by-destination-id).

Turpiniet tikai tad, kad pašreizējais galamērķa statuss atļauj izmaksu un tā valūta, metode un tīkls atbilst paredzētajai kustībai. Saņēmēja un galamērķa statusi ir neatkarīgi.

Izmantojiet `dst_` galamērķa ID izmaksas kotācijā. `rcp_` saņēmēja ID identificē īpašnieka ierakstu un nav kotācijas galamērķis.

Tālāk aizvediet gatavo galamērķi uz [Sūtīt līdzekļus](/lv/integration/send-funds).

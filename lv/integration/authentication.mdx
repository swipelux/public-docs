Turiet katru Swipelux API atslēgu aizsargātā aizmugursistēmā. Nekad neievietojiet atslēgu pārlūkprogrammas kodā, mobilās lietojumprogrammas komplektā vai klientam redzamā konfigurācijas failā.

## Nosūtiet savu API atslēgu

Izmantojiet kopīgo bāzes URL `https://platform.swipelux.com` un nosūtiet savu atslēgu galvenē `X-API-Key`.

```bash
export API_BASE='https://platform.swipelux.com'
export SWIPELUX_API_KEY='replace-with-your-api-key'

curl --request GET \
  "${API_BASE}/v3/capabilities" \
  --header "X-API-Key: ${SWIPELUX_API_KEY}"
```

[`GET /v3/capabilities`](/api-reference/capabilities/get-v3-capabilities) apstiprina, ka atslēga ir derīga un jūsu aizmugursistēma var sasniegt API.

## Smilšu kaste un produkcija

Smilšu kaste un produkcija izmanto vienu un to pašu API resursdatoru. API atslēga izvēlas vidi.

Uzturiet vides izvēli izvietošanas konfigurācijā. Produkcijas izvietošanai nekad nedrīkst atgriezties pie smilšu kastes atslēgas, un smilšu kastes izvietošanai nekad nedrīkst saņemt produkcijas akreditācijas datus.

## Droši glabājiet akreditācijas datus

Glabājiet smilšu kastes un produkcijas atslēgas atsevišķos noslēpumu pārvaldnieka ierakstos. Piešķiriet katrai aizmugursistēmas izvietošanai piekļuvi tikai tam ierakstam, kas tai nepieciešams.

Turiet atslēgas ārpus avota kontroles, žurnāliem, analītikas, atbalsta ekrānuzņēmumiem un kļūdu atbildēm. Rotējiet atslēgu, ja uzskatāt, ka tā ir tikusi atklāta.

Ja pieprasījums atgriež `unauthorized` vai `forbidden`, izmantojiet [Kļūdas un atkārtoti mēģinājumi](/lv/integration/errors), lai atšķirtu nederīgus akreditācijas datus no trūkstošām atļaujām.

Tālāk [konfigurējiet smilšu kastes testēšanu](/lv/integration/sandbox) vai sāciet [ātro startu](/lv/integration/quickstart).

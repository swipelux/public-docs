title: "Kļūdas un atkārtoti mēģinājumi"
description: "Apstrādājiet katru publisko Swipelux API problēmas kodu, izlemiet, kad atkārtot, un atrisiniet validācijas, stāvokļa, idempotences un platformas kļūmes."
---

Swipelux API kļūdas izmanto `application/problem+json` mediju tipu. Sazarojiet savas lietojumprogrammas uzvedību pēc stabilās `code` vērtības un pēc tam izmantojiet tālāk norādīto operāciju un norādes, lai atrisinātu kļūmi.

| Lauks | Kā to izmantot |
| --- | --- |
| `type` | Stabils dokumentācijas URI problēmas kodam. |
| `title` | Īss cilvēkiem lasāms problēmas nosaukums. |
| `status` | Ar šo atbildi saistītais HTTP statuss. |
| `code` | Stabila mašīnlasāma vērtība lietojumprogrammas loģikai. |
| `detail` | Kontekstuāls cilvēkiem lasāms teksts šim gadījumam. Neparsējiet un nesalīdziniet to. |
| `correlationId` | Pieprasījuma identifikators, ko saglabāt žurnālos un iekļaut, sazinoties ar atbalstu. |
| `retryable` | Kad `true`, tas pats pieprasījums vēlāk var izdoties. Kad `false`, mainiet pieprasījumu vai izpildiet priekšnosacījumu, pirms mēģināt vēlreiz. |
| `errors[]` | Lauka līmeņa validācijas detaļas, ieskaitot JSON Pointer, kad tas ir pieejams. |

Atkārtojiet idempotentus ierakstus ar sākotnējo `Idempotency-Key` un nemainītu metodi, ceļu un pamattekstu. Nekad neizmantojiet šo atslēgu atkārtoti citai paredzētai operācijai.

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**HTTP statuss:** `403`<br />
**Atkārtojams:** Nē<br />
**Problēmas tips:** `https://docs.swipelux.com/errors/forbidden`

**Nozīme:** API atslēga ir derīga, bet tai nav atļauts veikt šo operāciju.

**Kad tas notiek:** Akreditācijas datiem trūkst nepieciešamās atļaujas, vai produkcijas akreditācijas dati izsauc tikai smilšu kastei paredzētu galapunktu.

**Kā rīkoties:** Izmantojiet pareizajai videi paredzētus akreditācijas datus ar nepieciešamajām atļaujām. Neatklājiet un nemainiet atslēgas klienta puses kodā.

**Atkārtošanas norādes:** Neatkārtojiet nemainītu pieprasījumu. Pirms jauna pieprasījuma nosūtīšanas veiciet iepriekš norādīto darbību.

**Saistītās API operācijas:** Visas autentificētās API operācijas.

### `invalid_field_for_type`

**HTTP statuss:** `400`, `422`<br />
**Atkārtojams:** Netiek atgriezts<br />
**Problēmas tips:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**Nozīme:** Pieprasījums ietver laukus, kas nav derīgi izvēlētajam resursa tipam.

**Kad tas notiek:** Diskriminēts pieprasījums, piemēram, privātpersonas pretstatā uzņēmuma profilam, satur laukus no cita varianta vai izlaiž tā izvēlētā tipa obligātos laukus.

**Kā rīkoties:** Izmantojiet izvēlētā tipa shēmu, noņemiet citiem variantiem piederošos laukus, norādiet tā obligātos laukus un nosūtiet izlabotu pieprasījumu.

**Atkārtošanas norādes:** Šī problēma neatgriež `retryable`. Nepieņemiet, ka nemainīta pieprasījuma atkārtošana ir droša; sekojiet iepriekš norādītajai darbībai un operācijas idempotences prasībām.

**Saistītās API operācijas:**

- [`POST /v3/customers`](/api-reference/customers/post-v3-customers) (`postV3Customers`, statuss `400`)
- [`PATCH /v3/customers/{customerId}`](/api-reference/customers/patch-v3-customers-by-customer-id) (`patchV3CustomersByCustomerId`, statuss `400`)
- [`POST /v3/customers/{customerId}/export`](/api-reference/customers/post-v3-customers-by-customer-id-export) (`postV3CustomersByCustomerIdExport`, statuss `422`)
- [`POST /v3/customers/{customerId}/related-parties`](/api-reference/customers/post-v3-customers-by-customer-id-related-parties) (`postV3CustomersByCustomerIdRelated-parties`, statuss `400`)
- [`PATCH /v3/customers/{customerId}/related-parties/{relatedPartyId}`](/api-reference/customers/patch-v3-customers-by-customer-id-related-parties-by-related-party-id) (`patchV3CustomersByCustomerIdRelated-partiesByRelatedPartyId`, statuss `400`)

### `request_body_too_large`

**HTTP statuss:** `413`<br />
**Atkārtojams:** Nē<br />
**Problēmas tips:** `https://docs.swipelux.com/errors/request-body-too-large`

**Nozīme:** Pieprasījuma pamatteksts pārsniedz operācijas pieņemto lielumu.

**Kad tas notiek:** Uzdevuma iesniegums nosūta vairāk pieprasījuma datu, nekā API var apstrādāt vienā pamattekstā.

**Kā rīkoties:** Noņemiet nevajadzīgos datus, izmantojiet dokumentu atsauces, nevis iegultu faila saturu, un nosūtiet mazāku iesniegumu, kas joprojām atbild uz pašreizējām prasībām.

**Atkārtošanas norādes:** Neatkārtojiet nemainītu pieprasījumu. Pirms jauna pieprasījuma nosūtīšanas veiciet iepriekš norādīto darbību.

**Saistītās API operācijas:**

- [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) (`createCustomerTaskSubmission`, statuss `413`)

### `request_failed`

**HTTP statuss:** `502`, `503`<br />
**Atkārtojams:** Atkarīgs no konteksta<br />
**Problēmas tips:** `https://docs.swipelux.com/errors/request-failed`

**Nozīme:** Pakalpojums, kas nepieciešams operācijas pabeigšanai, sekmīgi neapstrādāja pieprasījumu.

**Kad tas notiek:** Klienta eksports, webhook pārvaldība vai smilšu kastes verifikācija sasniedz ārēja pakalpojuma kļūmi vai nepieejamu konfigurāciju.

**Kā rīkoties:** Pārbaudiet `retryable`. Atkārtojiet vēlāk, kad tā vērtība ir `true`; pretējā gadījumā saglabājiet `correlationId`, pārbaudiet pieprasījuma priekšnosacījumus un sazinieties ar atbalstu, ja kļūme saglabājas.

**Atkārtošanas norādes:** Nolasiet `retryable` šajā atbildē. Atkārtojiet vēlāk tikai tad, kad tā vērtība ir `true`. Idempotentam ierakstam atkārtoti izmantojiet sākotnējo idempotences atslēgu un nemainītu pieprasījumu.

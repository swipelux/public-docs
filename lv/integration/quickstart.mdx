---

Izveidojiet klientu, sagatavojiet vienu atkārtoti izmantojamu maku un izpildiet nepieciešamo smilšu kastes plūsmu.

## 1. Konfigurējiet smilšu kasti

Izmantojiet smilšu kastes API atslēgu no savas aizmugursistēmas:

```bash
export API_BASE='https://platform.swipelux.com'
export SWIPELUX_SANDBOX_API_KEY='replace-with-your-sandbox-key'
```

Atslēga izvēlas smilšu kastes vidi kopīgajā API resursdatorā.

## 2. Izveidojiet klientu

Izveidojiet privātpersonas klientu ar [`POST /v3/customers`](/api-reference/customers/post-v3-customers):

```bash
curl --request POST \
  "${API_BASE}/v3/customers" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Idempotency-Key: quickstart-customer-001" \
  --header "Content-Type: application/json" \
  --data '{"type":"individual","externalId":"quickstart-customer-001"}'
```

Saglabājiet `data.id` kā `CUSTOMER_ID`.

## 3. Izvēlieties rezultātu

- **Iemaksa:** saņemiet USD un norēķinieties ar USDC klienta izsniegtajā makā.
- **Izmaksa:** sūtiet USDC no klienta izsniegtā maka uz klienta bankas kontu.
- **Izsniegts bankas konts:** izsniedziet ACH/USD kontu, kas norēķinās klienta izsniegtajā makā.

Trešās puses izmaksai sekojiet [Saņēmēji](/lv/integration/recipients) vai [Sūtīt līdzekļus](/lv/integration/send-funds).

## 4. Atrodiet piemērotu iespēju

Uzskaitiet atbalstītās iespējas ar [`GET /v3/customers/{customerId}/capabilities/supported`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-supported):

```bash
curl --request GET \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/capabilities/supported" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}"
```

Izvēlieties atbildes ierakstu, kur `availability` ir iestatīts uz `available` vai `beta`, `eligibility.eligible` ir iestatīts uz `true`, ir nepieciešamie `directions` un `method`, kā arī atbilstošais `accountType`. Izmantojiet klienta izsniegto maku kā iemaksas galamērķi, izmaksas avotu vai bankas konta norēķinu kontu; izmantojiet klientam piederošo kontu kā `destinationId` šai izmaksas plūsmai. Ja tiek atgrieztas `institutions`, izmantojiet tikai kādu no atgrieztajām institūcijām. Saglabājiet ieraksta `id` kā `CAPABILITY_ID`; nekodējiet universālu iespējas ID.

## 5. Pieprasiet iespēju

Pieprasiet izvēlēto iespēju ar [`POST /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/post-v3-customers-by-customer-id-capabilities-by-capability-id):

```bash
curl --request POST \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/capabilities/${CAPABILITY_ID}" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Idempotency-Key: quickstart-capability-001" \
  --header "Content-Type: application/json" \
  --data '{}'
```

Saglabājiet `data.status` kā `CAPABILITY_STATUS` un `data.openTaskIds` kā `TASK_IDS`.

## 6. Pabeidziet iesaisti smilšu kastē

Ja `TASK_IDS` nav tukšs, pabeidziet katru pašreizējo prasību sadaļā [Iespējas un uzdevumi](/lv/integration/onboarding/capabilities-and-requirements).

Šai pastaigā iestatiet iespēju uz `ready` ar [`POST /v3/sandbox/customers/{customerId}/capabilities/{capabilityId}/status`](/api-reference/sandbox/post-v3-sandbox-customers-by-customer-id-capabilities-by-capability-id-status):

```bash
curl --request POST \
  "${API_BASE}/v3/sandbox/customers/${CUSTOMER_ID}/capabilities/${CAPABILITY_ID}/status" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Content-Type: application/json" \
  --data '{"status":"ready"}'
```

Šis testa kontrole nav produkcijas iesaiste. Atkārtoti ielādējiet ar [`GET /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id):

```bash
curl --request GET \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/capabilities/${CAPABILITY_ID}" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}"
```

Atsvaidziniet `CAPABILITY_STATUS` un `TASK_IDS` no `data.status` un `data.openTaskIds`. Turpiniet tikai tad, kad `CAPABILITY_STATUS` ir `ready`.

## 7. Veidojiet izvēlēto plūsmu

Izveidojiet vienu izsniegtu USDC maku uz Base tīkla ar [`POST /v3/customers/{customerId}/accounts`](/api-reference/accounts/post-v3-customers-by-customer-id-accounts):

```bash
curl --request POST \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/accounts" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Idempotency-Key: quickstart-flow-wallet-001" \
  --header "Content-Type: application/json" \
  --data '{"origin":"issued","type":"wallet","currency":"USDC","network":"base"}'
```

Saglabājiet `data.id` kā `FLOW_WALLET_ID`, `data.status` kā `FLOW_WALLET_STATUS` un `data.openTaskIds` kā `FLOW_WALLET_TASK_IDS`. Ja `FLOW_WALLET_TASK_IDS` nav tukšs, pabeidziet pašreizējos uzdevumus sadaļā [Iespējas un uzdevumi](/lv/integration/onboarding/capabilities-and-requirements).

Atkārtoti ielādējiet maku ar [`GET /v3/customers/{customerId}/accounts/{accountId}`](/api-reference/accounts/get-v3-customers-by-customer-id-accounts-by-account-id):

```bash
curl --request GET \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/accounts/${FLOW_WALLET_ID}" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}"
```

Atsvaidziniet `FLOW_WALLET_STATUS` un `FLOW_WALLET_TASK_IDS` no `data.status` un `data.openTaskIds`. Turpiniet tikai tad, kad `FLOW_WALLET_STATUS` ir `ready`.

  <Tab title="Izsniegts bankas konts">

Izveidojiet ACH/USD kontu, kas norēķinās uz gatavā maka, ar [`POST /v3/customers/{customerId}/accounts`](/api-reference/accounts/post-v3-customers-by-customer-id-accounts):

```bash
curl --request POST \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/accounts" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}" \
  --header "Idempotency-Key: quickstart-bank-account-001" \
  --header "Content-Type: application/json" \
  --data @- <<JSON
{"origin":"issued","type":"bank","method":"ach","country":"US","currency":"USD","settlement":{"accountId":"${FLOW_WALLET_ID}"}}
JSON
```

Saglabājiet `data.id` kā `BANK_ACCOUNT_ID`, pēc tam nolasiet nodrošinājumu ar [`GET /v3/customers/{customerId}/accounts/{accountId}`](/api-reference/accounts/get-v3-customers-by-customer-id-accounts-by-account-id):

```bash
curl --request GET \
  "${API_BASE}/v3/customers/${CUSTOMER_ID}/accounts/${BANK_ACCOUNT_ID}" \
  --header "X-API-Key: ${SWIPELUX_SANDBOX_API_KEY}"
```

Saglabājiet `data.status` kā `BANK_ACCOUNT_STATUS`, `data.details` kā `BANK_ACCOUNT_DETAILS` un `data.openTaskIds` kā `BANK_ACCOUNT_TASK_IDS`. Pabeidziet visus pašreizējos uzdevumus, pēc tam atkārtoti nolasiet kontu, līdz tā statuss atļauj lietošanu un ir pieejams `data.details`.

Bankas rekvizīti var nebūt pieejami uzreiz. Zars ir pabeigts, kad varat parādīt precīzus atkārtoti izmantojamus bankas rekvizītus, kas atgriezti sadaļā `BANK_ACCOUNT_DETAILS`. Nekad neveidojiet un nerādiet vietturu koordinātas, kamēr konts vēl tiek nodrošināts.

  </Tab>

curl --request GET \

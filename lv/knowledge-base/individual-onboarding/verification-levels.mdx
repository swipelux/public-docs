## KYC verifikācijas līmeņi

Swipelux izmanto trīs identitātes verifikācijas politikas līmeņus. Piemērojamais līmenis ir atkarīgs no klienta riska, jurisdikcijas, sagaidāmā darījumu apjoma un regulējuma prasībām.

<Warning>
  Šie līmeņi apraksta politikas klasifikācijas, nevis pašreizējos API enum.
  Pašreizējie uzdevumi nosaka prasības konkrētam klientam.
</Warning>

## Vienkāršota KYC

Vienkāršota KYC tiek izmantota apstiprinātām zema riska, zemas vērtības plūsmām.

### Nepieciešamā informācija

- Vārds
- Uzvārds
- Dzimšanas datums

### Kad to izmanto

- Darījumu summas ir zem piemērojamām vienkāršotām robežvērtībām
- Klients atrodas zema riska jurisdikcijā

## Standarta KYC

Standarta KYC verificē identitāti ar valsts izdotu dokumentu un pašbildi vai dzīvīguma pārbaudi.

### Nepieciešamie dokumenti

- Valsts izdots ID
- Pašbilde vai dzīvīguma pārbaude

### Pieņemtie ID dokumenti

- Pase
- Autovadītāja apliecība
- Valsts personas apliecība

## Pastiprināta KYC (pastiprināta pārbaude)

Pastiprināta KYC pievieno adreses un līdzekļu pierādījumus augstāka riska scenārijiem.

### Nepieciešamie dokumenti

- Viss, kas nepieciešams standarta KYC
- Adreses apliecinājums
- Līdzekļu apliecinājums

### Pastiprinātās KYC iniciatori

- Darījumu apjoms pārsniedz standarta robežvērtības
- Augsta riska jurisdikcija
- Atbilstības komandas marķējums, pamatojoties uz riska novērtējumu
- Regulējuma prasības

### Adreses apliecinājuma prasības

| Dokumenta veids | Prasības |
| --- | --- |
| Bankas izraksts | Izdots pēdējo 90 dienu laikā |
| Komunālais rēķins | Elektrība, gāze, ūdens vai internets; izdots pēdējo 90 dienu laikā |
| Valsts izdota vēstule | Nodokļu paziņojums vai oficiāla sarakste, izdota pēdējo 90 dienu laikā |

### Līdzekļu apliecinājuma prasības

| Dokumenta veids | Apraksts |
| --- | --- |
| Bankas izraksti | Nesenie izraksti, kas parāda pietiekamu atlikumu vai ienākumus |
| Algas kvītis | Nodarbinātības ienākumu verifikācija |
| Nodokļu deklarācijas | Ikgadēja nodokļu dokumentācija |
| Ieguldījumu izraksti | Brokera vai pensijas konta izraksti |

## Politikas līmeņi un pašreizējie uzdevumi

Pašreizējais uzdevuma saturs paliek patiesības avots nākamajai API darbībai. Tas var nodrošināt pirmās puses mitinātu sesiju, pieprasīt atbildes caur iesniegumu vai pieprasīt dokumentu pierādījumus.

Dažām pastiprinātām pārbaudēm atbilstības komanda var arī sazināties ar klienta reģistrēto e-pasta adresi. Uztveriet šo saziņu kā politikas pārbaudes koordināciju, nevis aizvietotāju pašreizējo API resursu lasīšanai.

Skatiet [privātpersonu iesaisti](/lv/integration/onboarding/customers#individual-customers), [Iespējas un uzdevumi](/lv/integration/onboarding/capabilities-and-requirements#complete-current-tasks) un [Integrācijas dokumentu ceļvedi](/lv/integration/onboarding/capabilities-and-requirements#upload-documents).

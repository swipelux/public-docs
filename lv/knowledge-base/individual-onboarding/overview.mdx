## Privātpersonu iesaiste (KYC)

Privātpersonu klienti pabeidz KYC pirms darījumu veikšanas. Verifikācijas līmenis ir atkarīgs no jurisdikcijas, darījumu apjoma, riska novērtējuma un regulējuma prasībām.

<Warning>
  Prasības atšķiras atkarībā no klienta, jurisdikcijas, iespējas un pārbaudes.
  Pašreizējie uzdevumi un ģenerētās shēmas nosaka, kas jāiesniedz.
</Warning>

## Ko aptver KYC

KYC apstiprina klienta identitāti un var pievienot adreses, dzīvīguma, finanšu profila vai līdzekļu avota pārbaudi, palielinoties riska un regulējuma prasībām. Prasības var atšķirties atkarībā no jurisdikcijas, darījumu apjoma un lietošanas gadījuma.

## KYC verifikācijas līmeņi

| Līmenis | Prasības | Tipisks lietošanas gadījums |
| --- | --- | --- |
| Vienkāršota | Vārds, uzvārds un dzimšanas datums | Apstiprinātas mazas vērtības plūsmas |
| Standarta | Valsts izdots ID un pašbilde/dzīvīguma pārbaude | Parasti darījumi standarta limitos |
| Pastiprināta | ID, pašbilde/dzīvīgums, adreses apliecinājums un līdzekļu apliecinājums | Lielas vērtības darījumi vai paaugstināta riska profili |

Vienkāršotais, standarta un pastiprinātais ir politikas līmeņi, nevis pašreizējās API statusa vērtības.

## Savāktā informācija

Atkarībā no pašreizējās pārbaudes Swipelux var pieprasīt:

- Juridisko vārdu un dzimšanas datumu
- Kontaktinformāciju
- Dzīvesvietas adresi, kad nepieciešams
- Valsts izdotus identitātes pierādījumus un dzīvīguma pierādījumus
- Finanšu profila informāciju, tostarp sagaidāmo darbību un līdzekļu avotu, kad nepieciešams

Neuztveriet šo sarakstu kā universālu pieprasījuma pamattekstu. Pašreizējā klienta shēma un uzdevuma detaļas nosaka informāciju, kas nepieciešama konkrētai iespējai.

## Pašreizējā ieviešana

Izveidojiet privātpersonas klientu, atklājiet un pieprasiet piemērotu iespēju, pēc tam sekojiet pašreizējiem uzdevumiem. Uzdevums var nodrošināt pirmās puses mitinātas verifikācijas sesijas vai pieprasīt uzdevuma iesniegumu. Augšupielādējiet dokumentus tikai tad, kad uzdevums to pieprasa.

Sekojiet [privātpersonu iesaistes ceļvedim](/lv/integration/onboarding/customers#individual-customers), [Iespējas un uzdevumi](/lv/integration/onboarding/capabilities-and-requirements#complete-current-tasks) un [privātpersonu API darbplūsmas kartei](/lv/knowledge-base/individual-onboarding/api-workflow).

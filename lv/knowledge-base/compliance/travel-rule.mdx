## Ceļošanas noteikuma atbilstība

Swipelux piemēro FATF 16. rekomendācijas kontroles, kad pārvedumi pārsniedz piemērojamo vietējo robežvērtību.

- **VASP-uz-VASP:** Swipelux identificē pretējo VASP un pārraida uzsācēja/labuma guvēja datus caur protokolu (TRISA/Notabene)
- **Nekastodiāli maki:**
  - (a) Swipelux savāc nepieciešamo uzsācēja/labuma guvēja informāciju
  - (b) Dati netiek pārraidīti, jo nav saņemošas VASP
  - (c) Pārvedumi var tikt bloķēti, ja blokķēdes analītika norāda uz augsta riska iesaisti

Saistītas API darbplūsmas: [saņēmēji](/lv/integration/recipients) un [sūtīt līdzekļus](/lv/integration/send-funds).

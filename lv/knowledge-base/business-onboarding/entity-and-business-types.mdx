## Vienības un uzņēmumu klasifikācijas jēdzieni

Swipelux izmanto šādus jēdzienus, lai klasificētu uzņēmumu KYB pārbaudes laikā.

<Warning>
  Šie apzīmējumi ir politikas klasifikācijas jēdzieni. Tie nav pašreizējie
  pieprasījuma enum vērtības, un tie negarantē, ka uzņēmums ir atbilstošs vai
  apstiprināts.
</Warning>

## Uzņēmuma vienību veidi

| Vienības veids | Apraksts |
| --- | --- |
| Limited Liability Company | LLC vai ekvivalents |
| Corporation | Vispārējs uzņēmums |
| S Corporation | ASV S korporācija |
| C Corporation | ASV C korporācija |
| Partnership | Vispārējs personālsabiedrība |
| Limited Partnership | Komandīts |
| Sole Proprietorship | Individuāli piederošs uzņēmums |
| Nonprofit | Bezpeļņas organizācija |
| Trust | Uzņēmējdarbības trests |
| Cooperative | Biedru piederošs kooperatīvs |
| DAO | Decentralizēta autonomā organizācija |
| Foundation | Fonda vienība |
| Other | Cita vienības forma |

- Būvniecība
- Profesionālie pakalpojumi

## Kā izmantot šos jēdzienus

Nepārveidojiet šo politikas katalogu par pieprasījuma vērtībām. Pašreizējās uzdevumu prasības nosaka vērtības, aprakstus un pierādījumus, ko iesniedzat konkrētam klientam un iespējai.

Pirms atbildēšanas izlasiet jaunāko uzdevumu. Skatiet [Iespējas un uzdevumi](/lv/integration/onboarding/capabilities-and-requirements#complete-current-tasks) pašreizējam ieviešanas modelim un [uzņēmumu iesaisti](/lv/integration/onboarding/customers#business-customers) klienta un saistīto pušu iestatīšanai.

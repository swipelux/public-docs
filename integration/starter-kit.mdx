The [public neobank starter](https://github.com/swipelux/neobank-starter) demonstrates customer onboarding, account views, quotes, transfers, and funding flows in one reference interface. The externally hosted starter is for built-in demo data only. Do not select `Go live`, and never enter any API key there.

## Run it locally

```bash
git clone https://github.com/swipelux/neobank-starter
cd neobank-starter
npm install
npm run dev
```

The local application starts with built-in demo data and does not require API configuration for that mode.

## Choose a data mode

- **Built-in demo data** lets you explore the interface without calling Swipelux.
- **Connected sandbox data** uses API responses authenticated by a sandbox key.

Connected sandbox mode is a private, disposable demo for your local browser. It exposes the sandbox key to browser code. It must not be shared or deployed. Never use a production key in this mode.

Use a backend for shared sandbox environments and every production integration. Keep API keys in a secret manager. Follow [Authentication](/integration/authentication) for the credential boundary.

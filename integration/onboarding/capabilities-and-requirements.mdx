---

Enable the capability that supports the customer's intended pay-in, payout, or bank-account flow.

## Choose and request a capability

List supported capabilities for the customer, choose an eligible option for the intended outcome, request it, and store its current status and open task IDs.

## Complete requirements

Read the current tasks and complete the requested hosted or API steps. Use the current task revision when submitting answers.

## Upload documents

Upload a requested document before submitting an answer that references it. Refetch the capability after completing its requirements.

## Next step

When the capability is ready, choose the matching workflow in [Common flows](/integration/common-flows).

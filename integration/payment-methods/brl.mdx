A BRL account gives your customer a Pix key that receives Pix payments. Deposits are credited to the customer's USDC settlement wallet. BRL payouts pay a Pix key or a Brazilian bank account.

## At a glance

| | |
| --- | --- |
| Currency | BRL |
| Method | Pix (`pix`) |
| Capabilities | `pix_named` for customers resident in Brazil, `pix_pooled` for everyone else |
| Receive | Issued accounts on `pix_named` or `pix_pooled` |
| Send | `pix_pooled`, funded with USDC |
| Who can pay in | On `pix_named`, only the customer's own bank account |

## Receive

Create an issued account with `method` set to `pix` and `currency` set to `BRL`. Name the `institution` the capability lists. Use `pix_named` for a customer resident in Brazil and `pix_pooled` for everyone else. See [Choose the bank](/integration/issue-bank-account#choose-the-bank).

A `pix_named` account accepts pay-ins only from the customer's own bank account (`payin.senders: "account_holder"`). A payment from anyone else is held for a `transaction_rfi` task, then credited or returned.

### Account details

The account returns `details.pixKey` and any `details.emv`. See [Present bank details safely](/integration/issue-bank-account#4-present-bank-details-safely).

## Send

BRL payouts need the customer's ready `pix_pooled` capability. Two [recipient destination](/integration/recipients) types receive BRL:

| Type | Pays | Fields |
| --- | --- | --- |
| `pix` | A Pix key | `pixKey`: a CPF or CNPJ in digits only, a phone number as `+55` and 10 or 11 digits, an email, or a random key |
| `pix_safe` | A Brazilian bank account | `taxId` (the holder's CPF or CNPJ), `bankCode` (the 8-digit ISPB code), `branchCode`, `accountNumber` with its check digit, `accountType` |

Responses and webhooks return `taxId` masked to its last four digits.

- Fund the payout with USDC and set `out.currency` to `BRL`. USDT cannot fund a BRL payout.
- A Pix payout carries no developer fee. If the source account has developer fees, set `fees.breakdown.developer` to `{"fixed": "0.00", "bips": 0}` in the quote.
- Swipelux prices the quote only after the destination's bank details are approved.

See [Pix payouts](/integration/send-funds#pix-payouts).

A EUR account gives your customer an IBAN that receives SEPA transfers. Deposits are credited to the customer's USDC settlement wallet. SEPA payouts send euros to a bank account in the customer's name or in the bank's name.

## At a glance

| | |
| --- | --- |
| Currency | EUR |
| Method | SEPA (`sepa`) |
| Capabilities | `sepa_named`, `sepa_pooled` |
| Bank | ClearBank Europe N.V. |
| Receive | Issued accounts on `sepa_named` |
| Send | SEPA payouts on `sepa_named` or `sepa_pooled` |

## Request the capability

EUR accounts and SEPA payouts are held at ClearBank Europe N.V., which decides on each application. Read the customer's supported capabilities. On `sepa_named`, each bank lists EUR and the `institution` to send when you open the account. See [Discover supported capabilities](/integration/onboarding/capabilities-and-requirements#discover-supported-capabilities).

## Receive

Create an issued account with `method` set to `sepa` and `currency` set to `EUR`. Name the `institution` the capability lists. Without it, the request returns `422 account_institution_required`. See [Choose the bank](/integration/issue-bank-account#choose-the-bank).

### Account details

The account returns `details.iban` and `details.bic`. When `referenceRequired` is `true`, show the exact `reference`. See [Present bank details safely](/integration/issue-bank-account#4-present-bank-details-safely).

## Send

A SEPA [recipient destination](/integration/recipients) needs `iban`, `accountHolderName`, and `country`. `bic` is optional. Its currency is EUR.

- With `sepa_named`, the payout is sent in the customer's own name.
- With `sepa_pooled`, the payout is sent in the bank's name.

A SEPA destination in another currency, or one created before November 21, 2026, reads `action_required` with `statusReason.code` set to `destination_provider_retired`. Create a new EUR SEPA destination with the same bank details.

Next, request `sepa_named` or `sepa_pooled` through [Capabilities and requirements](/integration/onboarding/capabilities-and-requirements#request-the-capability), then [issue a EUR bank account](/integration/issue-bank-account) or [create a SEPA destination](/integration/recipients).

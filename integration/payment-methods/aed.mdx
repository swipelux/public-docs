An AED account gives your customer one UAE IBAN that receives both IPP and FTS transfers. Deposits are credited to the customer's USDC settlement wallet. AED payouts go out over IPP.

## At a glance

| | |
| --- | --- |
| Currency | AED |
| Methods | IPP (`ipp`) and FTS (`fts`) |
| Capabilities | `ipp_named`, `fts_named`, covered by one bank approval |
| Bank | Zand Bank PJSC |
| Receive | One IBAN for IPP and FTS |
| Send | IPP on `ipp_named`. FTS only receives. |

## Receive

AED accounts are held at Zand Bank PJSC, and AED payouts go through the same bank. Create an issued account with `method` set to `ipp` or `fts` and `currency` set to `AED`. Name the `institution` the capability lists. Without it, an `ipp` request returns `422 account_institution_required`. See [Choose the bank](/integration/issue-bank-account#choose-the-bank).

The account returns `methods: ["ipp", "fts"]` and the `method` you requested. A second AED request at the same bank returns `409 conflict` with `holder.accountId`, which names the existing account.

### Account details

The account returns `details.iban` and `details.bic`. See [Present bank details safely](/integration/issue-bank-account#4-present-bank-details-safely).

## Send

An IPP [recipient destination](/integration/recipients) pays a UAE bank account in AED. Send a 23-character `iban` starting with `AE`. Swipelux removes spaces, uppercases it, and checks its format and checksum. `country` defaults to `AE`, and any currency other than AED returns `400 validation_error`.

- Payouts need the customer's ready `ipp_named` capability.
- The recipient needs `address.streetLine1`. Without it, the payout quote returns `400 validation_error`.
- The quote needs a payout `purpose` the bank accepts. See [Declare a payout purpose](/integration/quotes-and-transfers#declare-a-payout-purpose).

### Payout reference

On AED payouts, Swipelux sends the quote's `reference` to the bank as the payment memo, which the beneficiary may see. It can contain only ASCII letters, digits, spaces, `-`, `.`, and `/`, and cannot be one character repeated, such as `rr`. Any other value returns `400 validation_error`. See [Add a payout reference](/integration/quotes-and-transfers#add-a-payout-reference).

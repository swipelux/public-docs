A GBP account gives your customer a UK sort code and account number that receive Faster Payments from the customer's own bank account. Deposits are credited to the customer's USDC settlement wallet. GBP payouts use a separate pooled capability.

## At a glance

| | |
| --- | --- |
| Currency | GBP |
| Method | Faster Payments (`faster_payments`) |
| Bank | Banking Circle S.A. |
| Receive | `faster_payments_named` accounts, which only receive |
| Send | `faster_payments_pooled`, sent in the bank's name |
| Who can pay in | Only the customer's own bank account |

## Request the capability

GBP named accounts are held at Banking Circle S.A., and GBP payouts go through the same bank. It does not open accounts for businesses registered in, or individuals resident in, Algeria (`DZ`), Bangladesh (`BD`), Egypt (`EG`), India (`IN`), Indonesia (`ID`), Kenya (`KE`), Morocco (`MA`), Nigeria (`NG`), or Pakistan (`PK`). See [Check where an account can open](/integration/onboarding/capabilities-and-requirements#check-where-an-account-can-open).

## Receive

Create an issued account with `method` set to `faster_payments` and `currency` set to `GBP`. Name the `institution` the capability lists. Without it, the request returns `422 account_institution_required` with the `banks` you can name. See [Choose the bank](/integration/issue-bank-account#choose-the-bank).

The account accepts pay-ins only from the customer's own bank account (`payin.senders: "account_holder"`). A payment from anyone else is held for a `transaction_rfi` task, then credited or returned.

### Account details

The account returns `details.sortCode` and `details.accountNumber`. See [Present bank details safely](/integration/issue-bank-account#4-present-bank-details-safely).

## Send

A Faster Payments [recipient destination](/integration/recipients) pays a UK bank account in GBP. Send the 6-digit `sortCode` and the 8-digit `accountNumber`. Swipelux removes spaces and hyphens before it validates them. `country` defaults to `GB`, and any currency other than GBP returns `400 validation_error`.

Payouts need the customer's ready `faster_payments_pooled` capability. They are always sent in the bank's name, also for a customer with a `faster_payments_named` account.

Next, request `faster_payments_named` or `faster_payments_pooled` through [Capabilities and requirements](/integration/onboarding/capabilities-and-requirements#request-the-capability), then [issue a GBP bank account](/integration/issue-bank-account).

An NGN account gives your customer a NUBAN that receives NIP transfers. Deposits are credited to the customer's USDC settlement wallet. NGN payouts pay a Nigerian bank account over NIP.

## At a glance

| | |
| --- | --- |
| Currency | NGN |
| Method | NIP (`nip`) |
| Capability | `nip_pooled` |
| Receive | Issued accounts at a bank from the `banks` list, with the customer's BVN |
| Send | NIP payouts on `nip_pooled`, with no BVN |

## Request the capability

On `nip_pooled`, the `banks` list names the banks that open NGN accounts. Take the account's `institution` from `banks`, not from `institutions`, which can also include banks that serve quotes only. See [Check where an account can open](/integration/onboarding/capabilities-and-requirements#check-where-an-account-can-open).

## Receive

Create an issued account with `method` set to `nip` and `currency` set to `NGN`, and name the `institution`. See [Choose the bank](/integration/issue-bank-account#choose-the-bank).

An NGN account needs the customer's 11-digit Bank Verification Number (BVN) as a `bvn` tax identifier with country `NG`. Add it to the customer profile or a task submission. Without it, the request returns `422 account_bvn_required`.

### Account details

The account returns `details.nuban`, `details.bankName`, and `details.accountHolderName`. See [Present bank details safely](/integration/issue-bank-account#4-present-bank-details-safely).

## Send

A NIP [recipient destination](/integration/recipients) pays a Nigerian bank account in NGN. Send:

- `accountNumber`: the 10-digit NUBAN. Swipelux removes spaces and hyphens before it validates it.
- `bankId`: a bank from `GET /v3/recipients/banks?country=NG`. A `bankId` not on that list returns `400 recipient_destination_invalid`.

If the bank list is temporarily unavailable, either call returns `503 request_failed` with `retryable: true`. `country` defaults to `NG`, and any currency other than NGN returns `400 validation_error`. Payouts need the customer's ready `nip_pooled` capability and no BVN.

Next, request `nip_pooled` through [Capabilities and requirements](/integration/onboarding/capabilities-and-requirements#request-the-capability), then [issue an NGN bank account](/integration/issue-bank-account).

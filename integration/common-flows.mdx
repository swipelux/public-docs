Choose the outcome first, then use the capability and account model that supports it.

## Choose a flow

| Outcome | Typical sequence |
| --- | --- |
| Receive funds | Ready capability → destination wallet → quote → transfer → funding instructions |
| Send funds | Ready capability → funded source → account or recipient destination → quote → transfer |
| Issue a bank account | Ready capability → settlement wallet → issued bank account → provisioning |

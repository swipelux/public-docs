---
title: "Environments"
description: "Use one API base URL, let the API key select the environment, and call only documented sandbox helpers."
---

Production and sandbox use the same base URL: `https://platform.swipelux.com`. The environment is selected by the API key.

Sandbox helpers require sandbox context. The committed contract defines exactly these helpers:

| Summary | Operation |
| --- | --- |
| Credit a sandbox account | [`POST /v3/sandbox/accounts/{accountId}/topup`](/api-reference/sandbox/post-v3-sandbox-accounts-by-account-id-topup) |
| Force sandbox transfer state | [`POST /v3/sandbox/transfers/{transferId}/state`](/api-reference/sandbox/post-v3-sandbox-transfers-by-transfer-id-state) |
| Create sandbox task | [`POST /v3/sandbox/tasks`](/api-reference/sandbox/post-v3-sandbox-tasks) |
| Review sandbox task submission | [`POST /v3/sandbox/tasks/{taskId}/review`](/api-reference/sandbox/post-v3-sandbox-tasks-by-task-id-review) |
| Simulate customer verification | [`POST /v3/sandbox/customers/{customerId}/verification`](/api-reference/sandbox/post-v3-sandbox-customers-by-customer-id-verification) |
| Force sandbox capability status | [`POST /v3/sandbox/customers/{customerId}/capabilities/{capabilityId}/status`](/api-reference/sandbox/post-v3-sandbox-customers-by-customer-id-capabilities-by-capability-id-status) |

Open an operation page before calling a helper so your request uses its current body and response shape.

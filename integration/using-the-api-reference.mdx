title: "Using the API reference"
description: "Navigate generated operation pages and use stable contract links for exact API details."
---

The API Reference is generated from the committed `openapi.json`. Use it for exact operation parameters, request bodies, response fields, headers, error responses, and schema definitions.

Each operation has a stable `x-mint.href` deep link recorded in `openapi-coverage.json`. The guides use those links instead of copying full schemas.

## Find the exact contract

1. Start with the workflow in an Integration Docs guide.
2. Open the linked operation by HTTP method and path.
3. Check required headers, path and query parameters, request variants, response status codes, and referenced schemas.
4. Generate or validate your request against those exact fields.
5. Return to the guide for conceptual sequencing and operational boundaries.

<Note>
  Guides explain concepts and cross-operation workflows. Generated operation pages remain the source for exact fields.
</Note>

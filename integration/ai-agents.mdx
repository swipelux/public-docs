title: "Use Swipelux from your AI agent"

---

Connect an AI agent to your Swipelux account. The agent can run every API v3 operation that the permissions you grant allow: create customers, request capabilities, answer Tasks, upload documents, manage accounts and recipients, and quote and send transfers.

## Connect

<Tabs>
  <Tab title="Claude">
    In Claude, open **Customize > Connectors**, select **Add**, then **Add custom connector**, and enter:

    ```text Connector URL
    https://www.swipelux.app/api/mcp
    ```

    On Team and Enterprise plans, an Owner adds the connector once in **Organization settings > Connectors**, and members select **Connect**.
  </Tab>
  <Tab title="Claude Code">
    ```bash Install the plugin
    claude plugin marketplace add swipelux/agent-plugin
    claude plugin install swipelux-dev@swipelux
    ```

    Run `/mcp`, select the `swipelux` server, and sign in.
  </Tab>
  <Tab title="Codex">
    ```bash Install the plugin
    codex plugin marketplace add swipelux/agent-plugin
    codex plugin add swipelux-dev@swipelux
    ```

    Start a new Codex session and sign in when prompted.
  </Tab>
</Tabs>

Signing in opens Swipelux. Choose a space and the permissions the agent gets, then select **Connect**. If you use a passkey, confirm with it. Swipelux creates an MCP key for the agent. You need a role that can create API keys.

## Control access

- The agent works in the space you choose. Swipelux does not ask you again before the agent acts, including before it sends funds.
- Every permission your role can grant is selected by default. If the agent should not move money, clear **Create payouts**, **Create transfers**, and **Create and edit rules**. Only a role that can move funds can grant them.
- Each connected agent appears on the **Agents** page under **Your agents**, with its space. Select **Disconnect** to revoke its key. You can also revoke the key under **API Keys > MCP Keys** in that space.
- Each sign-in creates a new MCP key. Disconnect agents you no longer use.
- Start in a sandbox space to try flows without real money. See [Sandbox testing](/integration/sandbox).

## Connect without a browser sign-in

On the **API Keys** page, select **MCP key** to create a key. Send it in the `X-API-Key` header to `https://www.swipelux.app/api/mcp`.

```bash Claude Code
claude mcp add --transport http swipelux https://www.swipelux.app/api/mcp --header "X-API-Key: ${SWIPELUX_MCP_KEY}"
```

```toml Codex config.toml
[mcp_servers.swipelux]
url = "https://www.swipelux.app/api/mcp"
env_http_headers = { "X-API-Key" = "SWIPELUX_MCP_KEY" }
```

## Upload documents

Agents cannot send file contents through the connection. When a Task needs a document, the agent creates an upload link that works for 15 minutes. Open it and choose one file: a PDF or a JPEG, PNG, WebP, or HEIC image, up to 4 MB or the smaller limit the Task states. An agent that runs on your computer, such as Claude Code or Codex, can also upload a local file through the link.

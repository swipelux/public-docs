---
title: "Use Swipelux from your AI agent"
description: "Connect Claude, Claude Code, or Codex to your Swipelux account and run API v3 operations by asking."
---

Connect an AI agent to your Swipelux account. The agent can run every API v3 operation that the permissions you grant allow: create customers, request capabilities, answer Tasks, upload documents, manage accounts and recipients, and quote and send transfers.

## Connect

<Tabs>
  <Tab title="Claude">
    In Claude, open **Settings > Connectors > Add custom connector** and enter:

    ```text Connector URL
    https://www.swipelux.app/api/mcp
    ```
  </Tab>
  <Tab title="Claude Code">
    ```bash Install the plugin
    claude plugin marketplace add swipelux/agent-plugin
    claude plugin install swipelux@swipelux
    ```

    Run `/mcp`, select the Swipelux server, and sign in.
  </Tab>
  <Tab title="Codex">
    ```bash Install the plugin
    codex plugin marketplace add swipelux/agent-plugin
    codex plugin add swipelux@swipelux
    ```

    Start a new Codex session and sign in when prompted.
  </Tab>
</Tabs>

Signing in opens Swipelux. Choose a space and the permissions the agent gets, confirm with your passkey, then select **Connect**. Swipelux creates an MCP key for the agent. You need a role that can create API keys.

## Control access

- The permissions you select are the agent's only limits. Review them before connecting, and clear money movement permissions if the agent should not send funds.
- Each connection appears under **API Keys > MCP Keys**. Revoke the key to disconnect the agent.
- Start in a sandbox space to try flows without real money. See [Sandbox testing](/integration/sandbox).

## Connect without a browser sign-in

Create an MCP key under **API Keys > MCP Keys** and send it in the `X-API-Key` header to `https://www.swipelux.app/api/mcp`.

```bash Claude Code
claude mcp add --transport http swipelux https://www.swipelux.app/api/mcp --header "X-API-Key: ${SWIPELUX_MCP_KEY}"
```

```toml Codex config.toml
[mcp_servers.swipelux]
url = "https://www.swipelux.app/api/mcp"
env_http_headers = { "X-API-Key" = "SWIPELUX_MCP_KEY" }
```

## Upload documents

Agents cannot attach files directly. When a Task needs a document, the agent gives you an upload link that works for 15 minutes. Open it and choose the file, up to 4 MB or the smaller limit the Task states.

---
title: "Send funds"
description: "Send first-party or third-party payouts through compatible accounts and recipient destinations."
---

Outgoing movements start from a customer funding account and end at either a customer account or a recipient destination. Select the resource kind before you quote the movement.

<Warning>
Call payout operations from your backend with `X-API-Key`. Do not expose the key to a browser or client.
</Warning>

## Select source and destination

For a stablecoin-funded quote, `in.accountId` must identify an active issued custodial account owned by the request customer and compatible with `in.currency`. If you omit it, the scoped default issued account is used when the contract permits that selection.

For a first-party payout, use an `acc_` id for the customer account. For a third-party payout, use a `dst_` id for the recipient destination prepared through [Recipients](/integration/recipients).

Use `stablecoin_to_fiat` when the output lands in a compatible external bank account or bank destination. Use `stablecoin_move` for a compatible account or ready wallet destination on the same network and currency as the source. Raw inline addresses are not accepted; create a wallet destination first. There is no universal payout payload.

## Price and execute the payout

Create the quote with [`POST /v3/quotes`](/api-reference/money-movement/post-v3-quotes). This contract example targets a third-party fiat destination:

```json
{
  "customerId": "cus_7F3pL2nQ9xA5mW8kR1sT4v",
  "capabilityId": "ach_pooled",
  "in": {
    "amount": "150.00",
    "currency": "USDC"
  },
  "destinationId": "dst_2pQ4rT7mA9sL1kBc6dV8xN",
  "out": {
    "currency": "USD"
  }
}
```

Execute the selected quote with [`POST /v3/transfers`](/api-reference/money-movement/post-v3-transfers).

## Follow the current transfer

Read [`GET /v3/transfers/{transferId}`](/api-reference/money-movement/get-v3-transfers-by-transfer-id) after creation and after every transfer event. Use the current transfer `state`, `stateDetail`, and `openTaskIds` to decide whether to wait, stop, or follow current tasks.

Payout-side transfers are funded from the source account and do not have funding instructions. [`GET /v3/transfers/{transferId}/instructions`](/api-reference/money-movement/get-v3-transfers-by-transfer-id-instructions) returns `transfer_has_no_instructions` for that request.

## Replay writes safely

- [`POST /v3/quotes`](/api-reference/money-movement/post-v3-quotes) declares `Idempotency-Key`. Reuse a key only with the same body. Successful responses document `Idempotency-Replayed: true`.
- [`POST /v3/transfers`](/api-reference/money-movement/post-v3-transfers) declares `Idempotency-Key`. Reuse a key only with the same body. Successful responses document `Idempotency-Replayed: true`.

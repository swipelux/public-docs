---
title: "Sync and reconciliation"
description: "Paginate API resources and recover changes after missed webhook deliveries."
---

Keep local state aligned with Swipelux even when webhook delivery is delayed or missed.

## Read every page

Follow each returned cursor until no next page remains. When a list supports `updatedAfter`, read from a checkpoint with a small overlap and deduplicate resources by ID.

## Advance checkpoints safely

Apply the current resource state and advance the checkpoint only after the complete window succeeds. Reuse the previous checkpoint when any page fails.

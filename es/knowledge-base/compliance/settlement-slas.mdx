## Tiempos de liquidación

No estimes el tiempo de finalización de un cobro solo a partir de su método de pago. Los cortes bancarios, los días no hábiles, el procesamiento del proveedor y las acciones requeridas del cliente pueden afectar los tiempos.

Swipelux no publica un SLA fijo único para cada capacidad de cobro. Confirma cualquier requisito contractual de tiempos con Swipelux para la capacidad habilitada del cliente y sus países de operación.

### Elige una capacidad disponible

Obtén las capacidades del cliente y selecciona una que admita el cobro previsto. Usa el `data.id` de la capacidad devuelta como `capabilityId` al crear una cotización.

No codifiques de forma fija una lista de métodos de pago. Swipelux puede añadir métodos con el tiempo, y la disponibilidad puede variar según el cliente.

Consulta [capacidades y tareas](/es/integration/onboarding/capabilities-and-requirements) para el flujo de preparación. Después, sigue [recibir fondos](/es/integration/receive-funds) para crear y ejecutar la cotización.

### Sigue la transferencia

Tras la ejecución, consulta [`GET /v3/transfers/{transferId}`](/api-reference/money-movement/get-v3-transfers-by-transfer-id). Trata el `data.state` más reciente como la fuente de verdad.

Revisa `data.stateDetail` y `data.openTaskIds` cuando una transferencia requiera atención. Suscríbete a los [webhooks](/es/integration/webhooks) y mantén el estado sincronizado hasta que la transferencia alcance un resultado que tu producto gestione.

No marques una transferencia como completada a partir de un calendario previsto. Muestra a los clientes el estado actual de la transferencia.

## Conceptos de clasificación de entidad y negocio

Swipelux utiliza los siguientes conceptos para clasificar una empresa durante la revisión KYB.

<Warning>
  Estas etiquetas son conceptos de clasificación de política. No son enums de solicitud
  actuales y no garantizan que una empresa sea elegible o esté aprobada.
</Warning>

## Tipos de entidad de negocio

| Tipo de entidad | Descripción |
| --- | --- |
| Limited Liability Company | LLC o equivalente |
| Corporation | Corporación general |
| S Corporation | S corporation de EE. UU. |
| C Corporation | C corporation de EE. UU. |
| Partnership | Partnership general |
| Limited Partnership | Limited partnership |
| Sole Proprietorship | Negocio de propiedad individual |
| Nonprofit | Organización sin ánimo de lucro |
| Trust | Business trust |
| Cooperative | Cooperativa propiedad de sus miembros |
| DAO | Organización autónoma descentralizada |
| Foundation | Entidad tipo fundación |
| Other | Otra forma de entidad |

## Cómo utilizar estos conceptos

No traduzcas este catálogo de política a valores de solicitud. Los requisitos actuales de las tareas determinan los valores, descripciones y evidencia que envías para un cliente y capacidad concretos.

Lee la última tarea antes de responder. Consulta [Capacidades y tareas](/es/integration/onboarding/capabilities-and-requirements#complete-current-tasks) para el modelo de implementación actual y [onboarding de empresas](/es/integration/onboarding/customers#business-customers) para la configuración de clientes y partes relacionadas.

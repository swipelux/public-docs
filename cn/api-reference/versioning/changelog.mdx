如需将现有集成从较早版本升级，请参阅 [迁移到 v3](/cn/api-reference/versioning/migrate-to-v3)。

## 2026-08-24

**版本：** v3

### 新增
- API 密钥现在会公开 Rules API 的权限，因此你可以将密钥的范围限定为规则管理，与已有的范围并列。参见 [身份验证](/cn/integration/authentication)。
- 首次 payin 引导流程现在要求先设置 Polygon 客户钱包，然后才能继续。参见 [账户](/cn/integration/accounts)。

### 变更
- KYB 首页不再采集代表人的出生日期。该信息将在工作流后续步骤中收集。参见 [KYB 工作流](/cn/knowledge-base/business-onboarding/kyb-workflow)。
- 文档上传现在除了支持规范的 `image/jpeg` 之外，还接受 `image/jpg` MIME 别名。参见 [文档要求](/cn/knowledge-base/business-onboarding/document-requirements)。
- 任务历史隐藏了内部修订计数器。审核人将看到更简洁、更易于阅读的审计记录。参见 [能力与要求](/cn/integration/onboarding/capabilities-and-requirements)。
- UAEFTS v1 账户设置已停用。新的 AED 出金账户将使用当前的通道。

### 修复
- 当审核人添加新的文档提交时，RFI 表单会保留已有的填写内容，之前提交的答案不会在重新提交时丢失。
- 合规会话会保留有效链接，并遵循会话契约返回的显式操作，从而消除卡住的续接情况。
- 合规接受 ToS 流程的规范作用域名称，使用文档中所述作用域值的集成方可以顺利完成。
- 支付访问现在打开的是由应用拥有的入口，而不是过时的客户所有入口。
- KYB 演示引导与钱包契约保持一致，商户自身作为客户的条目不再出现在客户列表中。
- API 现在会以 `400` 错误拒绝格式错误的查询字符串编码，而不再静默地对请求进行归一化，从而更早地暴露无效输入。参见 [错误与重试](/integration/errors)。
- 文档上传接口会以 `400` 错误拒绝正文为空或格式错误的请求。

## 2026-08-17

**版本：** v3

### 新增
- 在 OpenAPI 规范中发布了 v3 Problem Details 目录，集成方可直接从架构中映射错误响应。 [Errors](/integration/errors).
- 在 v3 账户 webhook 事件中新增了 `customerId`，让您无需再进行一次读取即可将账户活动与其所属客户关联。参见 [Webhook](/cn/integration/webhooks)。
- 商户面板中完整覆盖 V3 个人档案字段，入驻操作员可查看并编辑通过 v3 API 收集的每个 KYC 字段。参见 [客户](/cn/integration/onboarding/customers)。
- 发布了 v3 的开发者迁移指南。参见 [迁移到 v3](/cn/api-reference/versioning/migrate-to-v3)。

### 变更
- 客户与账户的国家/地区代码在写入时现按已分配的 ISO 3166-1 alpha-2 值进行校验。读取时兼容遗留的存储值，因此现有记录仍可解析。参见 [账户与钱包](/cn/integration/accounts)。
- 的 USDC 可用性现按目的网络进行限定，因此报价与转账仅在目的地实际支持的网络上提供 USDC。
- `Capability.ready` 表示权限已获批准，并不表示账户已经签发。使用 `accountProvisioning` 跟踪账户签发状态：`not_applicable`、`not_started`、`in_progress`、`issued` 或 `failed`。
- 现已支持从 iPhone 上传 HEIC 作为身份和地址证明文件。

### 修复
- 重新执行已消费的报价现返回 `409 quote_execution_consumed`，而不是通用错误。参见 [报价与转账](/cn/integration/quotes-and-transfers)。
- 大规模历史结果下的转账列表读取与报价金额读取不再出现 `500`。
- 个人客户的关联方读取不再返回 `404`。
- 商户面板中的验证链接行现在每行都显示 **Open** 操作，每个钱包基础设施任务链接都会在需求视图中渲染。

## 治理与角色

### 责任矩阵

| 职责 | Swipelux(VASP) | 子商户 |
| --- | --- | --- |
| 加密资产托管 | 承担 | 不允许 |
| 链上执行 | 承担 | 不允许 |
| 用户核验(KYC) | 承担(直接执行或采用依赖模式) | 负责 UX 层的交接 |
| 制裁筛查 | 承担(所有用户) | 对自身员工承担 |
| 地域屏蔽 | 通过 IP/KYC 执行 | 必须在 UI 层实施 |
| 牌照 | 仅 VASP 牌照 | 行业牌照(例如博彩) |

### 责任划分

- **Swipelux:** 托管、链上执行、KYC/KYB、监控、Travel Rule、制裁筛查
- **子商户:** 用户旅程设计、地域屏蔽、行业垂直牌照、营销合规、避免主动向美国用户开展定向获客

在整个资金流中,Swipelux 是持牌的加密资产托管方。子商户从不持有、控制或访问用户资产或私钥。

相关 API 流程:[个人入驻](/cn/integration/onboarding/customers#individual-customers)与[企业入驻](/cn/integration/onboarding/customers#business-customers)。

## 可审计性与数据留存

依据欧盟 AML 法律和爱沙尼亚 MLTFPA 的要求,Swipelux 会将用户身份和交易数据留存 5 年。

数据主体的删除请求不适用于 AML 强制要求留存的记录。

Swipelux 将所有数据存储在符合 GDPR 的欧盟合规基础设施中。

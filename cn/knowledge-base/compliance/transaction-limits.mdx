## 交易限额

Swipelux 根据客户类型、核验级别和风险评估来设定交易限额。限额可能随着风险信息的变化而调整。

### 个人客户

| 限额类型 | 标准 KYC | 加强 KYC |
| --- | --- | --- |
| 单笔 | $10,000 | $50,000 |
| 每日 | $50,000 | $100,000 |
| 每月 | $100,000 | $250,000 |

### 企业客户

| 限额类型 | 金额 |
| --- | --- |
| 单笔 | $30,000 |
| 每日 | $100,000 |
| 每月 | $500,000 |

### 说明

依据我们的 AML 政策,限额可能根据风险评分进行调整。可能影响限额的因素包括:

- 交易历史与行为模式
- 地理因素
- 业务类型与所属行业
- 整体风险评估

关于具体限额或调整限额的问题,请联系合规团队。

关于具体实现,请参阅[个人入驻](/cn/integration/onboarding/customers#individual-customers)与[企业入驻](/cn/integration/onboarding/customers#business-customers)。

## 个人入驻 API 流程

请使用本映射,将个人 KYC 政策与当前生成的 API 参考对接起来。每一步都请以当前资源为准,不要将面向政策的标签实现为 API 状态机。

## 流程映射

### 1. 创建个人客户

使用 [`POST /v3/customers`](/api-reference/customers/post-v3-customers) 创建客户。保存返回的客户 id,并使用 [`GET /v3/customers/{customerId}`](/api-reference/customers/get-v3-customers-by-customer-id) 读取当前资源。

### 2. 发现并申请符合条件的能力

读取 [`GET /v3/customers/{customerId}/capabilities/supported`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-supported)。仅当某个变体当前的可用性和资格允许申请时,才使用 [`POST /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/post-v3-customers-by-customer-id-capabilities-by-capability-id) 进行申请。

### 3. 读取当前的能力与申请

读取 [`GET /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id) 与 [`GET /v3/customers/{customerId}/capabilities/{capabilityId}/applications`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id-applications)。请按当前的 open task id 推进,不要基于更早的响应就断定能力已就绪。

### 4. 获取当前任务详情

使用 [`GET /v3/customers/{customerId}/tasks`](/api-reference/tasks/list-customer-tasks) 列出客户任务。使用 [`GET /v3/customers/{customerId}/tasks/{taskId}`](/api-reference/tasks/get-customer-task) 获取有权限的可执行操作面。

任务详情可能会展示第一方托管会话 URL 以及当前可执行的要求。请使用其当前的版本与状态。

### 5. 完成托管会话或提交任务答案

当任务详情提供托管会话时,请仅将必要的会话数据返回给您的客户端,并将 API 密钥保留在您的后端。

当任务要求提交答案时,使用 [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) 创建一次完整、不可变的提交尝试。使用 [`GET /v3/customers/{customerId}/tasks/{taskId}/submissions/{submissionId}`](/api-reference/task-submissions/get-customer-task-submission) 读取当前的一次提交及其对外可见的结果。

### 6. 仅在被请求时上传材料

仅在当前任务要求时才上传材料。使用 [`POST /v3/customers/{customerId}/documents`](/api-reference/documents/post-v3-customers-by-customer-id-documents),然后将返回的 document id 填入对应的材料答案。

### 7. 重新获取当前资源

每次事件或操作后,重新获取当前的客户、能力、申请和任务。请根据它们最新的状态、原因、要求和 open task id 决定下一步。

## 生成的操作映射

| 资源 | 生成的操作 | 用途 |
| --- | --- | --- |
| Customers | [`POST /v3/customers`](/api-reference/customers/post-v3-customers) | 创建个人客户 |
| Customers | [`GET /v3/customers/{customerId}`](/api-reference/customers/get-v3-customers-by-customer-id) | 读取当前客户数据 |
| Capabilities | [`GET /v3/customers/{customerId}/capabilities/supported`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-supported) | 发现当前的可用性和资格 |
| Capabilities | [`POST /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/post-v3-customers-by-customer-id-capabilities-by-capability-id) | 申请所选的能力 |
| Capabilities | [`GET /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id) | 读取当前的能力状态和 open task |
| Capabilities | [`GET /v3/customers/{customerId}/capabilities/{capabilityId}/applications`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id-applications) | 读取机构申请及其 open task |
| Tasks | [`GET /v3/customers/{customerId}/tasks`](/api-reference/tasks/list-customer-tasks) | 列出客户名下的任务 |
| Tasks | [`GET /v3/customers/{customerId}/tasks/{taskId}`](/api-reference/tasks/get-customer-task) | 读取当前要求和托管会话 |
| Task Submissions | [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) | 提交一份完整的答案集 |
| Task Submissions | [`GET /v3/customers/{customerId}/tasks/{taskId}/submissions/{submissionId}`](/api-reference/task-submissions/get-customer-task-submission) | 读取有权限的答案快照与结果 |
| Documents | [`POST /v3/customers/{customerId}/documents`](/api-reference/documents/post-v3-customers-by-customer-id-documents) | 上传当前任务所请求的文件 |

## 政策与实现指引

Simplified、Standard 和 Enhanced KYC 是政策层级,它们不会替代当前能力、申请、任务、提交、要求或托管会话的状态。

关于实现细节,请遵循[个人入驻指南](/cn/integration/onboarding/customers#individual-customers)、[能力与任务](/cn/integration/onboarding/capabilities-and-requirements#complete-current-tasks),以及[集成 —— 上传材料指南](/cn/integration/onboarding/capabilities-and-requirements#upload-documents)。

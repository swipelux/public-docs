## KYC 核验级别

Swipelux 使用三个政策层级的身份核验。适用的层级取决于客户风险、司法辖区、预期交易量和监管要求。

<Warning>
  这些层级描述的是政策分类,而不是当前的 API 枚举值。特定客户的
  要求以当前任务为准。
</Warning>

## Simplified KYC

Simplified KYC 适用于已经批准的低风险、小额场景。

### 需要的信息

- 名(First name)
- 姓(Last name)
- 出生日期

### 使用场景

- 交易金额低于适用的简化门槛
- 客户位于低风险司法辖区

## Standard KYC

Standard KYC 通过政府签发的证件以及自拍或活体检查核验身份。

### 需要的材料

- 政府签发的证件
- 自拍或活体检查

### 可接受的证件类型

- 护照
- 驾照
- 身份证

## Enhanced KYC(强化尽职调查)

Enhanced KYC 会针对更高风险场景增加地址和资金证据。

### 需要的材料

- Standard KYC 所需的全部材料
- 地址证明
- 资金证明

### 触发条件

- 交易量超过标准门槛
- 高风险司法辖区
- 合规团队基于风险评估而标记
- 监管要求

### 地址证明要求

| 材料类型 | 要求 |
| --- | --- |
| 银行对账单 | 出具于过去 90 天内 |
| 水电燃气/网络费账单 | 水、电、燃气或网络;出具于过去 90 天内 |
| 政府信函 | 税务通知或官方信函,出具于过去 90 天内 |

### 资金证明要求

| 材料类型 | 说明 |
| --- | --- |
| 银行对账单 | 显示足够余额或收入的近期对账单 |
| 工资单 | 就业收入核验 |
| 税务申报表 | 年度税务材料 |
| 投资对账单 | 券商或退休账户对账单 |

## 政策层级与当前任务

当前任务的详情始终是下一步 API 动作的权威来源。它可能提供第一方托管的会话、通过提交请求答案,或者请求上传证据材料。

对于部分加强审核,合规团队还可能通过客户的注册邮箱与其联系。请将这种联系视为政策上的审核协调,不能替代读取当前 API 资源。

请参阅[个人入驻](/cn/integration/onboarding/customers#individual-customers)、[能力与任务](/cn/integration/onboarding/capabilities-and-requirements#complete-current-tasks),以及[集成 —— 上传材料指南](/cn/integration/onboarding/capabilities-and-requirements#upload-documents)。

## 个人入驻(KYC)

个人客户必须先完成 KYC,才能进行交易。核验级别取决于司法辖区、交易量、风险评估和监管要求。

<Warning>
  要求会因客户、司法辖区、能力和审核情况而不同。您必须提交的内容以当前
  任务和生成的 schema 为准。
</Warning>

## KYC 审核什么

KYC 用于确认客户身份,并可能随着风险和监管要求的提升,进一步引入地址、活体、财务画像或资金来源方面的审核。要求可能因司法辖区、交易量和使用场景而不同。

## KYC 核验级别

| 级别 | 要求 | 典型使用场景 |
| --- | --- | --- |
| Simplified | 姓名、姓氏与出生日期 | 已批准的小额流程 |
| Standard | 政府签发的证件与自拍/活体检查 | 在标准限额内的常规交易 |
| Enhanced | 证件、自拍/活体、地址证明和资金证明 | 大额交易或风险较高的画像 |

Simplified、Standard 和 Enhanced 是政策上的层级,不是当前的 API 状态值。

## 收集的信息

根据当前的审核情况,Swipelux 可能会请求:

- 法定姓名和出生日期
- 联系方式
- 需要时的住址
- 政府签发的身份证明和活体证据
- 需要时的财务画像信息,包括预期业务活动和资金来源

请勿将该列表视为通用的请求体。特定能力所需的信息以当前的客户 schema 和任务详情为准。

## 当前实现

创建个人客户,发现并申请符合条件的能力,然后按照当前任务操作。任务可能提供第一方托管的核验会话,或需要提交任务答案。仅在任务要求时才上传材料。

## 实体与业务分类概念

Swipelux 使用以下概念在 KYB 审核中对企业进行分类。

<Warning>
  这些标签是政策上的分类概念,不是当前请求的枚举值,也不代表某一企业
  一定符合资格或已经获批。
</Warning>

## 企业实体类型

| 实体类型 | 说明 |
| --- | --- |
| Limited Liability Company | 有限责任公司(LLC)或等同实体 |
| Corporation | 一般公司 |
| S Corporation | 美国 S 类公司 |
| C Corporation | 美国 C 类公司 |
| Partnership | 一般合伙 |
| Limited Partnership | 有限合伙 |
| Sole Proprietorship | 个人独资企业 |
| Nonprofit | 非营利组织 |
| Trust | 商业信托 |
| Cooperative | 会员制合作社 |
| DAO | 去中心化自治组织 |
| Foundation | 基金会实体 |
| Other | 其他实体形式 |

## 如何使用这些概念

请勿将这份政策目录直接翻译为请求值。您为某个特定客户和能力所提交的值、说明和证据材料,以当前任务的要求为准。

在响应之前,请阅读最新的任务。当前的实现模型请参阅[能力与任务](/cn/integration/onboarding/capabilities-and-requirements#complete-current-tasks),客户与相关方的创建请参阅[企业入驻](/cn/integration/onboarding/customers#business-customers)。

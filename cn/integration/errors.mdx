Swipelux API 错误使用 `application/problem+json` 媒体类型。请根据稳定的 `code` 值分支处理您的应用行为,然后使用下方的操作和指引解决失败。

| 字段 | 使用方式 |
| --- | --- |
| `type` | 该问题码的稳定文档 URI。 |
| `title` | 简短的人类可读问题标题。 |
| `status` | 与此响应关联的 HTTP 状态码。 |
| `code` | 供应用逻辑使用的稳定机器可读值。 |
| `detail` | 针对本次发生情况的上下文人类可读文本。请勿解析或比较该值。 |
| `correlationId` | 请求标识符,请保存在日志中,并在联系支持团队时一并提供。 |
| `retryable` | 为 `true` 时,同一请求稍后可能成功;为 `false` 时,请先修改请求或满足前置条件,再重新尝试。 |
| `errors[]` | 字段级验证详情,可用时包含 JSON Pointer。 |

重试幂等写入时,请使用原始的 `Idempotency-Key` 以及未更改的方法、路径和请求体。切勿将该键复用于不同的目标操作。

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**HTTP 状态码:** `403`<br />
**是否可重试:** 否<br />
**问题类型:** `https://docs.swipelux.com/errors/forbidden`

**含义:** 该 API 密钥有效,但无权执行此操作。

**发生场景:** 该凭据缺少所需权限,或生产凭据调用了仅限沙盒的端点。

**处理方法:** 使用具有所需权限的正确环境凭据。请勿在客户端代码中暴露或替换密钥。

**重试指引:** 请勿原样重试该请求。在发送新的请求之前,请先执行上述操作。

**相关 API 操作:** 所有需要身份验证的 API 操作。

### `invalid_field_for_type`

**HTTP 状态码:** `400`, `422`<br />
**是否可重试:** 不返回<br />
**问题类型:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**含义:** 请求包含对所选资源类型无效的字段。

**发生场景:** 带类型判别的请求(例如个人与企业资料)包含了另一变体的字段,或遗漏了所选类型必需的字段。

**处理方法:** 使用所选类型的模式,移除属于其他变体的字段,提供其必需字段,然后发送更正后的请求。

**重试指引:** 该问题不返回 `retryable`。不要假定原样重试是安全的;请遵循上述操作以及该操作的幂等性要求。

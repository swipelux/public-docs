title: "변경 이력"
description: "Swipelux API의 추가, 변경 및 지원 중단 사항을 추적합니다."
---

이 페이지에는 Swipelux API에 대한 날짜별 변경 사항이 나열되어 있습니다. 각 항목에는 영향을 받는 버전, 변경 유형, 그리고 통합 담당자에게 요구되는 조치가 명시되어 있습니다.

기존 통합을 이전 버전에서 업그레이드하려면 [v3로 마이그레이션](/api-reference/versioning/migrate-to-v3)을 참조하십시오.

## 미출시

_출시 예정인 변경 사항은 배포 전에 여기에 나열됩니다._

{/* Entry template

  ## YYYY-MM-DD

  **Version:** v3

  ### Added
  - Short description of the new endpoint, field, or event.

  ### Changed
  - Short description of the behavior or schema change. Note whether it is backward compatible.

  ### Deprecated
  - Endpoint or field being phased out, along with the replacement and removal date.

  ### Removed
  - Endpoint or field that is no longer available.

  ### Fixed
  - Bug fix visible to integrators.

  */}

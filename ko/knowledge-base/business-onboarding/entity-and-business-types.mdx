## 법인 및 기업 분류 개념

Swipelux는 KYB 검토 중 기업을 분류하기 위해 다음 개념을 사용해요.

<Warning>
  이 라벨은 정책 분류 개념이에요. 현재 요청 enum이 아니며,
  기업이 자격이 있거나 승인되었음을 보장하지 않아요.
</Warning>

## 기업 법인 유형

| 법인 유형 | 설명 |
| --- | --- |
| Limited Liability Company | LLC 또는 동등한 형태 |
| Corporation | 일반 법인 |
| S Corporation | US S corporation |
| C Corporation | US C corporation |
| Partnership | 일반 파트너십 |
| Limited Partnership | 유한 파트너십 |
| Sole Proprietorship | 개인 소유 기업 |
| Nonprofit | 비영리 조직 |
| Trust | 기업 신탁 |
| Cooperative | 조합원 소유 협동조합 |
| DAO | 탈중앙화 자율 조직 |
| Foundation | 재단 법인 |
| Other | 다른 법인 형태 |

## 이 개념 사용법

이 정책 카탈로그를 요청 값으로 번역하지 마세요. 특정 고객과 케이퍼빌리티에 대해 제출하는 값, 설명, 증거는 현재 태스크 요건이 결정해요.

응답하기 전에 최신 태스크를 조회하세요. 현재 구현 모델은 [케이퍼빌리티와 태스크](/ko/integration/onboarding/capabilities-and-requirements#complete-current-tasks)를, 고객과 관계자 설정은 [기업 온보딩](/ko/integration/onboarding/customers#business-customers)을 참고하세요.

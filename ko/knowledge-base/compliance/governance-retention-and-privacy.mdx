## 거버넌스와 역할

### 책임 매트릭스

| 책임 | Swipelux (VASP) | 서브 머천트 |
| --- | --- | --- |
| 크립토 커스터디 | 담당 | 허용되지 않음 |
| 블록체인 실행 | 담당 | 허용되지 않음 |
| 사용자 검증 (KYC) | 담당 (직접 또는 의존) | UX 핸드오프 담당 |
| 제재 스크리닝 | 담당 (모든 사용자) | 자체 직원에 대해 담당 |
| 지오블로킹 | IP/KYC로 강제 | UI 수준에서 구현 필요 |
| 라이선싱 | VASP 라이선스만 | 섹터 라이선스 (예: 게이밍) |

### 의무 매트릭스

- **Swipelux:** 커스터디, 블록체인 실행, KYC/KYB, 모니터링, 트래블 룰, 제재
- **서브 머천트:** 사용자 여정 설계, 지오블로킹, 업종 라이선싱, 마케팅 컴플라이언스, 요청하지 않은 미국 대상 방지

Swipelux는 흐름 내에서 규제 대상 크립토 커스터디언이에요. 서브 머천트는 사용자 자산이나 개인 키를 절대 보유, 통제, 접근하지 않아요.

관련 API 워크플로: [개인 온보딩](/ko/integration/onboarding/customers#individual-customers)과 [기업 온보딩](/ko/integration/onboarding/customers#business-customers).

## 감사 가능성과 보관

Swipelux는 EU AML 법률과 에스토니아의 MLTFPA에 따라 요구되는 대로 사용자 신원과 거래 데이터를 5년간 보관해요.

정보 주체의 삭제 요청은 AML로 의무화된 기록에 적용되지 않아요.

Swipelux는 GDPR에 부합하는 컴플라이언트한 EU 인프라 내에 모든 데이터를 저장해요.

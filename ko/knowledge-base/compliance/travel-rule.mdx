## 트래블 룰 컴플라이언스

Swipelux는 전송이 적용 가능한 로컬 임계값을 초과할 때 FATF 권고 16 통제를 적용해요.

- **VASP 대 VASP:** Swipelux는 상대방 VASP를 식별하고 프로토콜(TRISA/Notabene)을 통해 송신자/수취인 데이터를 전송해요
- **미호스팅 지갑:**
  - (a) Swipelux는 필수 송신자/수취인 정보를 수집해요
  - (b) 수신 VASP가 존재하지 않으므로 데이터가 전송되지 않아요
  - (c) 블록체인 분석에서 고위험 노출이 나타나면 전송이 차단될 수 있어요

관련 API 워크플로: [수취인](/ko/integration/recipients)과 [자금 지급](/ko/integration/send-funds).

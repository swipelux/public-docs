## 컴플라이언스 레퍼런스

Swipelux는 EU에서 인가받은 가상자산사업자(VASP)로 운영돼요. 이 섹션은 컴플라이언스 모델, 지원되는 관할권, 온보딩 요건, 결제 방법, 그리고 Swipelux와 서브 머천트 간의 책임 분담을 설명해요.

## 주제

### 일반 정보

규제 대상 기관으로서의 Swipelux의 역할과 서브 머천트와의 컴플라이언스 책임 분담 방식을 이해하세요.

**[일반 정보 ->](/ko/knowledge-base/compliance/regulatory-perimeter)**

### 지원 업종

기업 카테고리가 허용, 조건부, 금지 리스크 티어로 어떻게 분류되는지 확인하세요.

**[지원 업종 ->](/ko/knowledge-base/compliance/supported-business-models)**

### 관할권 프레임워크

지역별 최종 사용자 자격, 문서 요건, 결제 레일 가용성, 거래 한도를 검토하세요.

**[관할권 프레임워크 ->](/ko/knowledge-base/compliance/jurisdictions-and-availability)**

**[거래 한도 ->](/ko/knowledge-base/compliance/transaction-limits)**

### 최종 사용자 신원 검증 (KYC)

표준 검증과 승인된 의존 흐름을 포함한 개인 KYC 경로를 검토하세요.

**[KYC 검증 ->](/ko/knowledge-base/individual-onboarding/overview)**

**구현:** [개인 온보딩 API 워크플로](/ko/integration/onboarding/customers#individual-customers)

### 지갑 아키텍처와 페이아웃

커스터디 MPC 지갑과 자기 커스터디 출금 통제를 이해하세요.

**[지갑 아키텍처 ->](/ko/knowledge-base/compliance/custody-and-wallet-controls)**

### 결제 방법

지원되는 페이인 및 페이아웃 방법을 확인하세요.

**[결제 방법 ->](/ko/knowledge-base/compliance/payment-methods)**

### 머천트 온보딩 (KYB)

KYB 요건, 문서 수집, 강화된 실사(EDD) 트리거를 검토하세요.

**[머천트 온보딩 ->](/ko/knowledge-base/business-onboarding/overview)**

**구현:** [기업 온보딩 API 워크플로](/ko/integration/onboarding/customers#business-customers)

### 트래블 룰 컴플라이언스

VASP 간 전송과 미호스팅 지갑 거래에 대한 FATF 권고 16 통제를 이해하세요.

**[트래블 룰 ->](/ko/knowledge-base/compliance/travel-rule)**

### 스크리닝과 모니터링

제재, PEP, 블록체인 분석, 거래 모니터링 통제를 검토하세요.

**[스크리닝과 모니터링 ->](/ko/knowledge-base/compliance/screening-and-monitoring)**

### 거버넌스와 역할

Swipelux와 서브 머천트가 데이터 보관을 포함해 책임을 어떻게 분담하는지 확인하세요.

**[거버넌스 ->](/ko/knowledge-base/compliance/governance-retention-and-privacy)**

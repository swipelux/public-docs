## 결제 방법

Swipelux는 페이인과 페이아웃을 위해 여러 정산 레일을 오케스트레이션해요.

### 지원되는 페이인 방법

1. **법정화폐 예치 (사용자 -> Swipelux)**
   - 오픈 뱅킹: 즉시 SEPA / Faster Payments
   - 카드 인수: Visa/Mastercard (MCC 제한 적용)

2. **크립토 예치 (사용자 -> Swipelux)**
   - 사용자는 USDC와 같은 지원 자산을 분리된 MPC 지갑으로 직접 예치할 수 있어요. 지갑은 제3자 서비스 제공자에 의해 스크리닝돼요.

3. **제3자 애그리게이터**
   - Swipelux는 인가된 제3자 파트너의 오케스트레이션된 정산을 지원해요. Swipelux는 이 흐름에서 지갑 제공자 및 최종 정산 대리인 역할을 해요.

구현 가이드는 [자금 수취](/ko/integration/receive-funds)를 참고하세요.

### 지원되는 페이아웃 방법

**법정화폐 페이아웃 (Swipelux -> 사용자)**

- **흐름:** 스테이블코인 -> Swipelux 유동성 -> 법정화폐 전환 -> 사용자 은행 계좌
- **규칙:** 페이아웃은 검증된 KYC 사용자의 정확한 법적 이름으로 된 은행 계좌로만 전송될 수 있어요. 이 흐름에서 제3자 페이아웃은 지원되지 않아요.

위의 정확한 이름 제한은 이 직접 사용자 은행 페이아웃 흐름에 적용돼요. [수취인](/ko/integration/recipients)에 설명된 별도의 v3 recipient-destination 흐름을 대체하지는 않아요.

구현 가이드는 [자금 지급](/ko/integration/send-funds)을 참고하세요.

description: "모든 공개 Swipelux API 문제 코드를 처리하고, 재시도 시점을 판단하고, 유효성 검사, 상태, 멱등성 및 플랫폼 오류를 해결하세요."
---

Swipelux API 오류는 `application/problem+json` 미디어 타입을 사용합니다. 안정적인 `code` 값에 따라 애플리케이션 동작을 분기한 다음, 아래의 작업과 지침을 사용하여 오류를 해결하세요.

| 필드 | 사용 방법 |
| --- | --- |
| `type` | 문제 코드에 대한 안정적인 문서 URI입니다. |
| `title` | 사람이 읽을 수 있는 짧은 문제 제목입니다. |
| `status` | 이 응답과 연결된 HTTP 상태입니다. |
| `code` | 애플리케이션 로직에 사용하는 안정적인 기계 판독 가능 값입니다. |
| `detail` | 이번 발생에 대한 상황별 텍스트입니다. 파싱하거나 비교하지 마세요. |
| `correlationId` | 로그에 저장하고 지원팀에 문의할 때 포함할 요청 식별자입니다. |
| `retryable` | `true`이면 동일한 요청이 나중에 성공할 수 있습니다. `false`이면 다시 시도하기 전에 요청을 변경하거나 전제 조건을 충족하세요. |
| `errors[]` | 사용 가능한 경우 JSON 포인터를 포함하는 필드 수준 유효성 검사 세부 정보입니다. |

멱등한 쓰기 작업은 원래의 `Idempotency-Key`와 변경하지 않은 메서드, 경로, 본문으로 재시도하세요. 해당 키를 의도가 다른 작업에 절대 재사용하지 마세요.

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `request_failed`

**HTTP 상태:** `502`, `503`<br />
**재시도 가능:** 상황에 따라 다름<br />
**문제 유형:** `https://docs.swipelux.com/errors/request-failed`

**의미:** 작업을 완료하는 데 필요한 서비스가 요청을 성공적으로 처리하지 못했습니다.

**발생 시점:** 고객 내보내기, 웹훅 관리 또는 샌드박스 검증이 외부 서비스 장애 또는 사용할 수 없는 구성에 도달합니다.

**해결 방법:** `retryable`을 확인하세요. 값이 `true`이면 나중에 재시도하고, 그렇지 않으면 `correlationId`를 보관하고 요청 전제 조건을 확인한 후 장애가 지속되면 지원팀에 문의하세요.

**재시도 지침:** 이 응답의 `retryable`을 확인하세요. 값이 `true`일 때만 나중에 재시도하세요. 멱등성 쓰기의 경우 원래의 멱등성 키와 변경하지 않은 요청을 재사용하세요.

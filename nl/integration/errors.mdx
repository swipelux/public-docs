Swipelux API-fouten gebruiken het mediatype `application/problem+json`. Vertak je applicatiegedrag op de stabiele `code`-waarde en gebruik daarna de bewerking en de richtlijnen hieronder om de fout op te lossen.

| Veld | Hoe je het gebruikt |
| --- | --- |
| `type` | Stabiele documentatie-URI voor de probleemcode. |
| `title` | Korte leesbare probleemtitel. |
| `status` | HTTP-status die bij deze respons hoort. |
| `code` | Stabiele machineleesbare waarde voor applicatielogica. |
| `detail` | Contextuele leesbare tekst voor dit voorval. Parse of vergelijk deze niet. |
| `correlationId` | Request-identifier om in logs op te slaan en mee te sturen wanneer je contact opneemt met support. |
| `retryable` | Bij `true` kan hetzelfde request later slagen. Bij `false` wijzig je het request of vervul je eerst een voorwaarde voordat je het opnieuw probeert. |
| `errors[]` | Validatiedetails op veldniveau, inclusief een JSON Pointer wanneer beschikbaar. |

Herhaal idempotente writes met de oorspronkelijke `Idempotency-Key` en de ongewijzigde methode, het pad en de body. Hergebruik die sleutel nooit voor een andere beoogde bewerking.

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**HTTP-status:** `403`<br />
**Opnieuw te proberen:** Nee<br />
**Probleemtype:** `https://docs.swipelux.com/errors/forbidden`

**Betekenis:** De API-key is geldig maar mag deze bewerking niet uitvoeren.

**Wanneer het optreedt:** De credential mist een vereiste permissie, of een productiecredential roept een endpoint aan dat alleen voor sandbox is.

**Wat te doen:** Gebruik een credential voor de juiste omgeving met de vereiste permissies. Stel keys niet bloot in client-side code en vervang ze daar ook niet.

**Richtlijnen voor nieuwe pogingen:** Probeer het ongewijzigde request niet opnieuw. Pas de bovenstaande actie toe voordat je een nieuw request verstuurt.

### `invalid_field_for_type`

**HTTP-status:** `400`, `422`<br />
**Opnieuw te proberen:** Niet geretourneerd<br />
**Probleemtype:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**Betekenis:** Het request bevat velden die niet geldig zijn voor het geselecteerde resourcetype.

**Wanneer het optreedt:** Een gediscrimineerd request, zoals een individueel-versus-bedrijfsprofiel, bevat velden van een andere variant of laat velden weg die het geselecteerde type vereist.

**Wat te doen:** Gebruik het schema van het geselecteerde type, verwijder velden die bij andere varianten horen, lever de vereiste velden aan en verstuur een gecorrigeerd request.

**Richtlijnen voor nieuwe pogingen:** Dit probleem retourneert geen `retryable`. Ga er niet van uit dat een ongewijzigde nieuwe poging veilig is; volg de bovenstaande actie en de idempotency-vereisten van de bewerking.

### `request_body_too_large`

**HTTP-status:** `413`<br />
**Opnieuw te proberen:** Nee<br />
**Probleemtype:** `https://docs.swipelux.com/errors/request-body-too-large`

**Betekenis:** De request-body overschrijdt de omvang die de bewerking accepteert.

**Wanneer het optreedt:** Een taakinzending verstuurt meer requestdata dan de API in één body kan verwerken.

**Wat te doen:** Verwijder onnodige data, gebruik documentverwijzingen in plaats van ingesloten bestandsinhoud en verstuur een kleinere inzending die de huidige vereisten nog steeds beantwoordt.

**Richtlijnen voor nieuwe pogingen:** Probeer het ongewijzigde request niet opnieuw. Pas de bovenstaande actie toe voordat je een nieuw request verstuurt.

**Relevante API-bewerkingen:**

### `unauthorized`

**HTTP-status:** `401`<br />
**Opnieuw te proberen:** Nee<br />
**Probleemtype:** `https://docs.swipelux.com/errors/unauthorized`

**Betekenis:** Het request mist een geldige API-key.

**Wanneer het optreedt:** De `X-API-Key`-header ontbreekt, is ongeldig, is verlopen of wordt niet herkend door de API.

**Wat te doen:** Verstuur de juiste omgevingsspecifieke key vanaf een beschermde backend. Roteer de key als deze mogelijk is blootgesteld.

**Richtlijnen voor nieuwe pogingen:** Probeer het ongewijzigde request niet opnieuw. Pas de bovenstaande actie toe voordat je een nieuw request verstuurt.

**HTTP-status:** `400`<br />
**Opnieuw te proberen:** Nee<br />
**Probleemtype:** `https://docs.swipelux.com/errors/unknown-parameter`

**Betekenis:** Het request bevat een niet-ondersteunde of onbekende parameter.

**Wanneer het optreedt:** Een querystring- of bewerkingsparameter is verkeerd gespeld, wordt niet ondersteund of wordt niet geaccepteerd door dat endpoint.

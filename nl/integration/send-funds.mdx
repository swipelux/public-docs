---
title: "Geld versturen"
description: "Verstuur een Swipelux-uitbetaling vanuit een klant-wallet naar een eigen bankrekening, andere wallet of third-party recipient in fiat of stablecoin."
---

Elke uitbetaling begint vanuit een ready, gefinancierde uitgegeven wallet. Het bestemmingsmodel hangt af van wie het eindpunt bezit.

```mermaid
flowchart TD
  A["Funded issued wallet"] --> B{"Who owns the endpoint?"}
  B -->|"Customer"| C["Customer account acc_..."]
  B -->|"Another person or business"| D["Recipient destination dst_..."]
  C --> E["Create quote"]
  D --> E
  E --> F["Execute and track transfer"]
```

## Voordat je begint

Refetch de bron-wallet. Bevestig dat de huidige status de uitbetaling toestaat en dat het beschikbare saldo het beoogde bronbedrag dekt. Bewaar de ID uit de respons als `SOURCE_WALLET_ID`.

Je hebt ook een ready uitbetalingscapability nodig voor de huidige klant en geselecteerde destination.

Bestaande Tron-wallets kunnen USDT naar een andere Tron-wallet versturen met een `stablecoin_transfers`-quote. De input en output moeten hetzelfde netwerk en dezelfde stablecoin gebruiken. Je kunt geen nieuwe uitgegeven wallets op Tron aanmaken.

## 2. Maak de uitbetalingsquote

Gebruik [`POST /v3/quotes`](/api-reference/money-movement/post-v3-quotes) met deze headers:

```http
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: payout-quote-001
Content-Type: application/json
```

```json
{
  "customerId": "${CUSTOMER_ID}",
  "capabilityId": "${CAPABILITY_ID}",
  "in": {
    "amount": "150.00",
    "currency": "USDC",
    "accountId": "${SOURCE_WALLET_ID}"
  },
  "destinationId": "${PAYOUT_DESTINATION_ID}",
  "out": {
    "currency": "USD"
  }
}
```

Bewaar `data.id` als `QUOTE_ID` en toon de geretourneerde prijs en fees.

### Kies een bankroute {#choose-a-bank-route}

Voor een crypto-naar-fiat-uitbetaling kun je de optionele `institutionId` instellen om een goedgekeurde bankroute voor de klant te vereisen. Laat deze weg om automatische routering te gebruiken.

```json
{
  "customerId": "${CUSTOMER_ID}",
  "capabilityId": "${CAPABILITY_ID}",
  "institutionId": "${INSTITUTION_ID}",
  "in": {
    "amount": "150.00",
    "currency": "USDC",
    "accountId": "${SOURCE_WALLET_ID}"
  },
  "destinationId": "${PAYOUT_DESTINATION_ID}",
  "out": {
    "currency": "USD"
  }
}
```

- Een expliciete `institutionId` valt nooit terug op een andere bank. Wanneer de geselecteerde bank geen ready route heeft voor deze klant, capability en destination, retourneert `POST /v3/quotes` `422` [`bank_not_supported_for_customer`](/integration/errors#bank-not-supported-for-customer) met de pointer `/institutionId`.
- `institutionId` is alleen geldig bij crypto-naar-fiat-uitbetalingsquotes. Als je deze meestuurt bij een pay-in-, kaart- of stablecoin-transferquote, wordt `400` [`validation_error`](/integration/errors#validation-error) geretourneerd.
- Reads van quotes en transfers geven de `institutionId` van de geselecteerde route terug, ook van een automatisch geselecteerde route, wanneer de bank kan worden geïdentificeerd.

### SWIFT-uitbetalingen {#swift-payouts}

In productie hebben USD SWIFT-uitbetalingen een ready SWIFT-capability nodig die uitbetalingen ondersteunt (`swift_pooled` of `swift_named`), en worden ze gefinancierd met USDC op Ethereum, Base of Polygon, of met USDT op Ethereum of Polygon. Het bedrag voor de ontvanger na fees moet minimaal 100.00 USD zijn.

Een SWIFT-destination heeft het straatadres van de bank nodig in `bankAddress`, `bankCity`, `bankState` en `bankPostalCode`. Het BIC-land moet overeenkomen met het land van de bank. Swipelux haalt het adres van de begunstigde uit het profiel van de klant of recipient.

## 3. Voer de uitbetaling uit

Maak de transfer met [`POST /v3/transfers`](/api-reference/money-movement/post-v3-transfers). Gebruik één nieuwe key voor deze beoogde uitvoering:

```http
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: payout-transfer-001
Content-Type: application/json
```

```json
{
  "quoteId": "${QUOTE_ID}"
}
```

Bewaar transfer `data.id` als `TRANSFER_ID`. Een succesvolle create start de uitbetaling; het bewijst niet dat deze is bezorgd.

## 4. Volg de bezorging

Lees [`GET /v3/transfers/{transferId}`](/api-reference/money-movement/get-v3-transfers-by-transfer-id) na aanmaken en na elke event. Gebruik de nieuwste `data.state`, `data.stateDetail` en `data.openTaskIds` om te beslissen of je wacht, handelt of een terminale uitkomst toont.

Bekijk vervolgens [Quotes en transfers](/nl/integration/quotes-and-transfers) voor exacte bedragen, veilige uitvoeringsrecovery en transfertaken.

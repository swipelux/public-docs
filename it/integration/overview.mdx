## Come funziona un'integrazione

```mermaid
%%{init: {"flowchart": {"rankSpacing": 20, "nodeSpacing": 16, "wrappingWidth": 80, "padding": 8}}}%%
flowchart LR
  A["Crea cliente"] --> B["Attiva la capability"]
  B --> C["Completa i task aperti"]
  C --> D["Crea un conto o una destinazione"]
  D --> E["Esegui il flusso selezionato"]
  E --> F["Monitora gli aggiornamenti con i webhook"]
```

Un cliente è l'individuo o l'azienda che possiede il flusso. Le capability descrivono quali risultati quel cliente può utilizzare. I task aperti indicano cosa deve essere completato prima che la capability o la risorsa possa procedere.

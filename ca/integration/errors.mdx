title: "Errors i reintents"
description: "Gestiona cada codi de problema de l'API pública de Swipelux, decideix quan reintentar i resol fallades de validació, estat, idempotència i plataforma."
---

Els errors de l'API de Swipelux utilitzen el tipus de mèdia `application/problem+json`. Ramifica el comportament de la teva aplicació segons el valor estable de `code` i, a continuació, utilitza l'operació i les indicacions següents per resoldre la fallada.

| Camp | Com utilitzar-lo |
| --- | --- |
| `type` | URI de documentació estable per al codi de problema. |
| `title` | Títol curt del problema llegible per humans. |
| `status` | Estat HTTP associat a aquesta resposta. |
| `code` | Valor estable llegible per màquines per a la lògica de l'aplicació. |
| `detail` | Text contextual llegible per humans per a aquesta ocurrència. No l'analitzis ni el comparis. |
| `correlationId` | Identificador de sol·licitud per emmagatzemar als registres i incloure quan contactis amb el suport. |
| `retryable` | Quan és `true`, la mateixa sol·licitud pot tenir èxit més tard. Quan és `false`, canvia la sol·licitud o satisfés un requisit previ abans de tornar-ho a intentar. |
| `errors[]` | Detalls de validació a nivell de camp, incloent-hi un punter JSON quan estigui disponible. |

Reintenta les escriptures idempotents amb la `Idempotency-Key` original i el mètode, camí i cos sense canvis. No reutilitzis mai aquesta clau per a una operació prevista diferent.

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**Estat HTTP:** `403`<br />
**Reintentable:** No<br />
**Tipus de problema:** `https://docs.swipelux.com/errors/forbidden`

**Significat:** La clau d'API és vàlida però no té permís per realitzar aquesta operació.

**Quan es produeix:** La credencial no té un permís requerit, o una credencial de producció crida un endpoint exclusiu de sandbox.

**Què fer:** Utilitza una credencial per a l'entorn correcte amb els permisos requerits. No exposis ni substitueixis claus al codi del costat del client.

**Guia de reintent:** No reintentis la sol·licitud sense canvis. Aplica l'acció anterior abans d'enviar una altra sol·licitud.

**Operacions d'API rellevants:** Totes les operacions d'API autenticades.

### `invalid_field_for_type`

**Estat HTTP:** `400`, `422`<br />
**Reintentable:** No es retorna<br />
**Tipus de problema:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**Significat:** La sol·licitud inclou camps que no són vàlids per al tipus de recurs seleccionat.

**Quan es produeix:** Una sol·licitud discriminada, com ara un perfil de particular versus d'empresa, conté camps d'una altra variant o omet camps requerits pel tipus seleccionat.

**Què fer:** Utilitza l'esquema del tipus seleccionat, elimina els camps que pertanyen a altres variants, proporciona els seus camps requerits i envia una sol·licitud corregida.

**Guia de reintent:** Aquest problema no retorna `retryable`. No assumeixis que un reintent sense canvis és segur; segueix l'acció anterior i els requisits d'idempotència de l'operació.

### `request_body_too_large`

**Estat HTTP:** `413`<br />
**Reintentable:** No<br />
**Tipus de problema:** `https://docs.swipelux.com/errors/request-body-too-large`

**Significat:** El cos de la sol·licitud supera la mida acceptada per l'operació.

**Quan es produeix:** Un enviament de tasca envia més dades de sol·licitud de les que l'API pot processar en un sol cos.

**Què fer:** Elimina les dades innecessàries, utilitza referències de documents en lloc d'incrustar el contingut dels fitxers i envia un enviament més petit que continuï responent els requisits actuals.

**Guia de reintent:** No reintentis la sol·licitud sense canvis. Aplica l'acció anterior abans d'enviar una altra sol·licitud.

**Operacions d'API rellevants:**

- [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) (`createCustomerTaskSubmission`, estat `413`)

### `unauthorized`

**Estat HTTP:** `401`<br />
**Reintentable:** No<br />
**Tipus de problema:** `https://docs.swipelux.com/errors/unauthorized`

**Significat:** A la sol·licitud li falta una clau d'API vàlida.

**Quan es produeix:** La capçalera `X-API-Key` és absent, no vàlida, caducada o no reconeguda per l'API.

**Què fer:** Envia la clau correcta específica de l'entorn des d'un backend protegit. Rota la clau si pot haver estat exposada.

**Guia de reintent:** No reintentis la sol·licitud sense canvis. Aplica l'acció anterior abans d'enviar una altra sol·licitud.

**Operacions d'API rellevants:** Totes les operacions d'API autenticades.

### `unknown_parameter`

**Estat HTTP:** `400`<br />
**Reintentable:** No<br />
**Tipus de problema:** `https://docs.swipelux.com/errors/unknown-parameter`

**Significat:** La sol·licitud inclou un paràmetre no suportat o desconegut.

**Quan es produeix:** Un paràmetre de la cadena de consulta o de l'operació està mal escrit, no està suportat o no és acceptat per aquest endpoint.

**Què fer:** Elimina el paràmetre desconegut o substitueix-lo per un paràmetre exacte documentat per a l'operació.

**Guia de reintent:** No reintentis la sol·licitud sense canvis. Aplica l'acció anterior abans d'enviar una altra sol·licitud.

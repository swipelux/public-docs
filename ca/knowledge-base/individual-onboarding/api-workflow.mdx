## Flux de treball d'API d'incorporació d'individus

Utilitza aquest mapa per connectar la política KYC individual amb la referència actual generada de l'API. Segueix el recurs actual a cada pas en lloc d'implementar etiquetes des de la política com una màquina d'estats de l'API.

## Mapa del flux de treball

### 1. Crea el client individual

Crea el client amb [`POST /v3/customers`](/api-reference/customers/post-v3-customers). Emmagatzema l'id del client retornat i llegeix el recurs actual amb [`GET /v3/customers/{customerId}`](/api-reference/customers/get-v3-customers-by-customer-id).

### 2. Descobreix i sol·licita una capacitat elegible

Llegeix [`GET /v3/customers/{customerId}/capabilities/supported`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-supported). Selecciona una variant només quan la seva disponibilitat i elegibilitat actuals permetin la sol·licitud, i després utilitza [`POST /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/post-v3-customers-by-customer-id-capabilities-by-capability-id).

### 3. Llegeix la capacitat actual i les aplicacions

Llegeix [`GET /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id) i [`GET /v3/customers/{customerId}/capabilities/{capabilityId}/applications`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id-applications). Segueix els ids de tasca oberts actuals en lloc d'assumir la preparació a partir d'una resposta anterior.

### 4. Obté el detall actual de la tasca

Llista les tasques del client amb [`GET /v3/customers/{customerId}/tasks`](/api-reference/tasks/list-customer-tasks). Obté la superfície d'acció autoritzada amb [`GET /v3/customers/{customerId}/tasks/{taskId}`](/api-reference/tasks/get-customer-task).

El detall de la tasca pot exposar URLs de sessions allotjades de primera part i els requisits accionables actuals. Utilitza la seva revisió i estat actuals.

### 5. Completa les sessions allotjades o envia respostes de tasca

Quan el detail de la tasca proporcioni una sessió allotjada, retorna només les dades de sessió requerides al teu client i manté la clau d'API al teu backend.

Quan la tasca requereixi respostes, crea un intent complet immutable amb [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission). Llegeix un enviament actual i el seu resultat públic amb [`GET /v3/customers/{customerId}/tasks/{taskId}/submissions/{submissionId}`](/api-reference/task-submissions/get-customer-task-submission).

### 6. Puja documents només quan sigui sol·licitat

Puja documents només quan la tasca actual ho demani. Utilitza [`POST /v3/customers/{customerId}/documents`](/api-reference/documents/post-v3-customers-by-customer-id-documents), i després col·loca l'id del document retornat a la resposta de document aplicable.

### 7. Torna a obtenir els recursos actuals

Torna a obtenir el client, la capacitat, les aplicacions i la tasca actuals després de cada esdeveniment o acció. Utilitza els seus estats, motius, requisits i ids de tasca oberts més recents per seleccionar el següent pas.

## Mapa d'operacions generades

| Recurs | Operació generada | Ús |
| --- | --- | --- |
| Customers | [`POST /v3/customers`](/api-reference/customers/post-v3-customers) | Crea el client individual |
| Customers | [`GET /v3/customers/{customerId}`](/api-reference/customers/get-v3-customers-by-customer-id) | Llegeix dades actuals del client |
| Capabilities | [`GET /v3/customers/{customerId}/capabilities/supported`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-supported) | Descobreix disponibilitat i elegibilitat actuals |
| Capabilities | [`POST /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/post-v3-customers-by-customer-id-capabilities-by-capability-id) | Sol·licita la capacitat seleccionada |
| Capabilities | [`GET /v3/customers/{customerId}/capabilities/{capabilityId}`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id) | Llegeix l'estat actual de la capacitat i les tasques obertes |
| Capabilities | [`GET /v3/customers/{customerId}/capabilities/{capabilityId}/applications`](/api-reference/capabilities/get-v3-customers-by-customer-id-capabilities-by-capability-id-applications) | Llegeix les aplicacions d'institució i les seves tasques obertes |
| Tasks | [`GET /v3/customers/{customerId}/tasks`](/api-reference/tasks/list-customer-tasks) | Llista les tasques pertanyents al client |
| Tasks | [`GET /v3/customers/{customerId}/tasks/{taskId}`](/api-reference/tasks/get-customer-task) | Llegeix els requisits actuals i les sessions allotjades |
| Task Submissions | [`POST /v3/customers/{customerId}/tasks/{taskId}/submissions`](/api-reference/task-submissions/create-customer-task-submission) | Envia un conjunt complet de respostes |
| Task Submissions | [`GET /v3/customers/{customerId}/tasks/{taskId}/submissions/{submissionId}`](/api-reference/task-submissions/get-customer-task-submission) | Llegeix la instantània autoritzada de resposta i el resultat |
| Documents | [`POST /v3/customers/{customerId}/documents`](/api-reference/documents/post-v3-customers-by-customer-id-documents) | Puja un fitxer sol·licitat per la tasca actual |

## Orientació de política i implementació

El KYC simplificat, estàndard i reforçat són nivells de política. No substitueixen els estats actuals de capacitat, aplicació, tasca, enviament, requisit o sessió allotjada.

Per als detalls d'implementació, segueix la [guia d'incorporació d'individus](/ca/integration/onboarding/customers#individual-customers), [Capacitats i tasques](/ca/integration/onboarding/capabilities-and-requirements#complete-current-tasks) i la [guia de documents de la integració](/ca/integration/onboarding/capabilities-and-requirements#upload-documents).

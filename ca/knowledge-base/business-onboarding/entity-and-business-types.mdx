## Conceptes de classificació d'entitat i negoci

Swipelux utilitza els conceptes següents per classificar un negoci durant la revisió KYB.

<Warning>
  Aquestes etiquetes són conceptes de classificació de política. No són valors enum de sol·licitud
  actuals i no garanteixen que un negoci sigui elegible o aprovat.
</Warning>

## Tipus d'entitat de negoci

| Tipus d'entitat | Descripció |
| --- | --- |
| Limited Liability Company | LLC o equivalent |
| Corporation | Corporació general |
| S Corporation | Corporació S dels EUA |
| C Corporation | Corporació C dels EUA |
| Partnership | Societat general |
| Limited Partnership | Societat limitada |
| Sole Proprietorship | Empresa de propietat individual |
| Nonprofit | Organització sense ànim de lucre |
| Trust | Trust de negoci |
| Cooperative | Cooperativa de membres propietaris |
| DAO | Organització autònoma descentralitzada |
| Foundation | Entitat de fundació |
| Other | Una altra forma d'entitat |

## Com utilitzar aquests conceptes

No tradueixis aquest catàleg de política en valors de sol·licitud. Els requisits actuals de tasca determinen els valors, descripcions i proves que presentes per a un client i capacitat en particular.

Llegeix la tasca més recent abans de respondre. Consulta [Capacitats i tasques](/ca/integration/onboarding/capabilities-and-requirements#complete-current-tasks) per al model d'implementació actual i [incorporació de negocis](/ca/integration/onboarding/customers#business-customers) per a la configuració de client i de parts relacionades.

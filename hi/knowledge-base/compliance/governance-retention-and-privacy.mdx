## Governance और Roles

### Liability Matrix

| जिम्मेदारी | Swipelux (VASP) | Sub-Merchant |
| --- | --- | --- |
| Crypto Custody | जिम्मेदार | अनुमति नहीं |
| Blockchain Execution | जिम्मेदार | अनुमति नहीं |
| User Verification (KYC) | जिम्मेदार (Direct या Reliance) | UX Handoff के लिए जिम्मेदार |
| Sanctions Screening | जिम्मेदार (सभी Users) | अपने staff के लिए जिम्मेदार |
| Geoblocking | IP/KYC के माध्यम से लागू करता है | UI स्तर पर लागू करना होगा |
| Licensing | केवल VASP License | Sector License (जैसे Gaming) |

### जिम्मेदारी Matrix

- **Swipelux:** custody, blockchain execution, KYC/KYB, monitoring, Travel Rule, sanctions
- **Sub-merchant:** user journey design, geoblocking, vertical licensing, marketing compliance, unsolicited US targeting की रोकथाम

Swipelux flow में regulated crypto custodian है। Sub-merchants कभी भी user assets या private keys को नहीं रखते, नियंत्रित नहीं करते, या access नहीं करते।

संबंधित API workflows: [individual onboarding](/hi/integration/onboarding/customers#individual-customers) और [business onboarding](/hi/integration/onboarding/customers#business-customers)।

## Auditability & Retention

Swipelux EU AML कानूनों और Estonia के MLTFPA के तहत आवश्यक अनुसार user identity और transactional data को 5 वर्षों तक retain करता है।

Data subject deletion requests AML-mandated records पर लागू नहीं होते।

Swipelux सभी data को GDPR के अनुरूप compliant EU infrastructure में संग्रहीत करता है।

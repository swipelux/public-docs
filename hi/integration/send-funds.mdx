प्रत्येक payout एक ready, funded issued wallet से शुरू होता है। Destination model इस पर निर्भर करता है कि endpoint का स्वामी कौन है।

## शुरू करने से पहले

Source wallet को पुन: प्राप्त करें। पुष्टि करें कि इसकी वर्तमान status payout की अनुमति देती है और इसका available balance इच्छित source amount को cover करता है। इसकी response से प्राप्त ID को `SOURCE_WALLET_ID` के रूप में संग्रहीत करें।

आपको वर्तमान customer और चयनित destination के लिए एक ready payout capability भी चाहिए।

मौजूदा Tron wallets एक `stablecoin_transfers` quote के साथ किसी अन्य Tron wallet को USDT भेज सकते हैं। Input और output को एक ही network और stablecoin का उपयोग करना होगा। आप Tron पर नए issued wallets नहीं बना सकते।

## 1. Destination तैयार करें

Content-Type: application/json

{
  "origin": "external",

  "methods": ["ach", "wire"],
  "country": "US",
  "currency": "USD",
  "details": {
    "routingNumber": "021000021",

## 2. Payout quote बनाएँ

इन headers के साथ [`POST /v3/quotes`](/api-reference/money-movement/post-v3-quotes) का उपयोग करें:

```http Request headers
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: payout-quote-001
Content-Type: application/json
```

```json Request body
{
  "customerId": "${CUSTOMER_ID}",
  "capabilityId": "${CAPABILITY_ID}",
  "in": {
    "amount": "150.00",
    "currency": "USDC",
    "accountId": "${SOURCE_WALLET_ID}"
  },
  "destinationId": "${PAYOUT_DESTINATION_ID}",
  "out": {
    "currency": "USD"
  }
}
```

`data.id` को `QUOTE_ID` के रूप में संग्रहीत करें और लौटाए गए price और fees प्रस्तुत करें।

### Bank route चुनें {#choose-a-bank-route}

Crypto-to-fiat payout के लिए, आप customer के लिए एक approved bank route अनिवार्य करने हेतु वैकल्पिक `institutionId` सेट कर सकते हैं। Automatic routing का उपयोग करने के लिए इसे छोड़ दें।

```json Request body with institutionId
{
  "customerId": "${CUSTOMER_ID}",
  "capabilityId": "${CAPABILITY_ID}",
  "institutionId": "${INSTITUTION_ID}",
  "in": {
    "amount": "150.00",
    "currency": "USDC",
    "accountId": "${SOURCE_WALLET_ID}"
  },
  "destinationId": "${PAYOUT_DESTINATION_ID}",
  "out": {
    "currency": "USD"
  }
}
```

- एक explicit `institutionId` कभी भी किसी अन्य bank पर fall back नहीं करता। जब चयनित bank के पास इस customer, capability और destination के लिए कोई ready route नहीं होता, तो `POST /v3/quotes` pointer `/institutionId` के साथ `422` [`bank_not_supported_for_customer`](/integration/errors#bank-not-supported-for-customer) लौटाता है।
- `institutionId` केवल crypto-to-fiat payout quotes पर मान्य है। इसे pay-in, card या stablecoin transfer quote पर भेजने से `400` [`validation_error`](/integration/errors#validation-error) लौटता है।
- जब bank की पहचान की जा सकती है, तो quote और transfer reads चयनित route का `institutionId` लौटाते हैं, जिसमें automatically चयनित route भी शामिल है।

### SWIFT payouts {#swift-payouts}

Production में, USD SWIFT payouts के लिए एक ready SWIFT capability चाहिए जो payouts को support करती हो (`swift_pooled` या `swift_named`), और इन्हें Ethereum, Base या Polygon पर USDC से, या Ethereum या Polygon पर USDT से fund किया जाता है। Fees के बाद recipient amount कम से कम 100.00 USD होना चाहिए।

एक SWIFT destination को `bankAddress`, `bankCity`, `bankState` और `bankPostalCode` में bank का street address चाहिए। BIC country को bank country से मेल खाना चाहिए। Swipelux beneficiary address को customer या recipient profile से लेता है।

## 3. Payout execute करें

Transfer को [`POST /v3/transfers`](/api-reference/money-movement/post-v3-transfers) के साथ बनाएँ। इस इच्छित execution के लिए एक नई key का उपयोग करें:

```http Request headers
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: payout-transfer-001
Content-Type: application/json
```

```json Request body
{
  "quoteId": "${QUOTE_ID}"
}
```

Transfer `data.id` को `TRANSFER_ID` के रूप में संग्रहीत करें। एक सफल create payout शुरू करता है; यह delivery साबित नहीं करता।

## 4. Delivery track करें

Creation के बाद और प्रत्येक event के बाद [`GET /v3/transfers/{transferId}`](/api-reference/money-movement/get-v3-transfers-by-transfer-id) पढ़ें। नवीनतम `data.state`, `data.stateDetail`, और `data.openTaskIds` का उपयोग करके तय करें कि प्रतीक्षा करें, कार्य करें, या terminal outcome दिखाएँ।

आगे, सटीक amounts, सुरक्षित execution recovery, और transfer tasks के लिए [Quotes और transfers](/hi/integration/quotes-and-transfers) की समीक्षा करें।

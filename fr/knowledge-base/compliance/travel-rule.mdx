## Conformité Travel Rule

Swipelux applique les contrôles de la Recommandation 16 du GAFI lorsque les transferts dépassent le seuil local applicable.

- **VASP à VASP :** Swipelux identifie le VASP de contrepartie et transmet les données Émetteur/Bénéficiaire via un protocole (TRISA/Notabene)
- **Portefeuilles non hébergés :**
  - (a) Swipelux collecte les informations Émetteur/Bénéficiaire requises
  - (b) Aucune donnée n'est transmise puisqu'il n'existe pas de VASP destinataire
  - (c) Les transferts peuvent être bloqués si l'analytique blockchain indique une exposition à haut risque

Workflows API associés : [destinataires](/fr/integration/recipients) et [envoyer des fonds](/fr/integration/send-funds).

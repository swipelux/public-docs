## Concepts de classification d'entité et d'entreprise

Swipelux utilise les concepts suivants pour classer une entreprise lors de l'examen KYB.

<Warning>
  Ces étiquettes sont des concepts de classification de politique. Ce ne sont pas des énumérations
  de requête actuelles, et elles ne garantissent pas qu'une entreprise soit éligible ou approuvée.
</Warning>

## Types d'entités professionnelles

| Type d'entité | Description |
| --- | --- |
| Limited Liability Company | LLC ou équivalent |
| Corporation | Société générale |
| S Corporation | Société S américaine |
| C Corporation | Société C américaine |
| Partnership | Société en nom collectif |
| Limited Partnership | Société en commandite |
| Sole Proprietorship | Entreprise individuelle |
| Nonprofit | Organisation à but non lucratif |
| Trust | Trust d'entreprise |
| Cooperative | Coopérative détenue par ses membres |
| DAO | Organisation autonome décentralisée |
| Foundation | Entité de fondation |
| Other | Autre forme d'entité |

## Comment utiliser ces concepts

Ne traduisez pas ce catalogue de politique en valeurs de requête. Les exigences de tâche actuelles déterminent les valeurs, les descriptions et les preuves que vous soumettez pour un client et une capacité particuliers.

Lisez la dernière tâche avant de répondre. Consultez [Capacités et tâches](/fr/integration/onboarding/capabilities-and-requirements#complete-current-tasks) pour le modèle d'implémentation actuel et [onboarding professionnel](/fr/integration/onboarding/customers#business-customers) pour la configuration du client et des parties liées.

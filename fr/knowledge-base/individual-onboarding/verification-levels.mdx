## Niveaux de vérification KYC

Swipelux utilise trois niveaux politiques de vérification d'identité. Le niveau applicable dépend du risque client, de la juridiction, du volume de transactions attendu et des exigences réglementaires.

<Warning>
  Ces niveaux décrivent des classifications politiques plutôt que des énumérations API actuelles.
  Les tâches actuelles déterminent les exigences pour un client spécifique.
</Warning>

## KYC simplifié

Le KYC simplifié est utilisé pour les flux à faible risque et faible valeur approuvés.

### Informations requises

- Prénom
- Nom
- Date de naissance

### Quand il est utilisé

- Les montants des transactions sont inférieurs aux seuils simplifiés applicables
- Le client se trouve dans une juridiction à faible risque

## KYC standard

Le KYC standard vérifie l'identité avec un document délivré par le gouvernement et un selfie ou un contrôle de vivacité.

### Documents requis

- Pièce d'identité délivrée par le gouvernement
- Selfie ou contrôle de vivacité

### Documents d'identité acceptés

- Passeport
- Permis de conduire
- Carte d'identité nationale

## KYC renforcé (due diligence renforcée)

Le KYC renforcé ajoute des preuves d'adresse et de fonds pour les scénarios à risque plus élevé.

### Documents requis

- Tout ce qui est requis pour le KYC standard
- Justificatif de domicile
- Preuve de fonds

### Déclencheurs du KYC renforcé

- Le volume des transactions dépasse les seuils standard
- Juridiction à haut risque
- Signalement de l'équipe de conformité basé sur l'évaluation des risques
- Exigences réglementaires

### Exigences de justificatif de domicile

| Type de document | Exigences |
| --- | --- |
| Relevé bancaire | Émis dans les 90 derniers jours |
| Facture de services publics | Électricité, gaz, eau ou internet ; émise dans les 90 derniers jours |
| Lettre délivrée par le gouvernement | Avis fiscal ou correspondance officielle émise dans les 90 derniers jours |

### Exigences de preuve de fonds

| Type de document | Description |
| --- | --- |
| Relevés bancaires | Relevés récents montrant un solde ou un revenu suffisant |
| Fiches de paie | Vérification du revenu d'emploi |
| Déclarations fiscales | Documentation fiscale annuelle |
| Relevés d'investissement | Relevés de compte de courtage ou de retraite |

## Niveaux politiques et tâches actuelles

Le détail de la tâche actuelle reste la source de vérité pour la prochaine action API. Il peut fournir une session hébergée de première partie, demander des réponses via une soumission ou demander des preuves documentaires.

Pour certains examens renforcés, l'équipe de conformité peut également contacter l'adresse e-mail enregistrée du client. Traitez ce contact comme une coordination d'examen politique, non comme un substitut à la lecture des ressources API actuelles.

Consultez [onboarding individuel](/fr/integration/onboarding/customers#individual-customers), [Capacités et tâches](/fr/integration/onboarding/capabilities-and-requirements#complete-current-tasks), et le [guide des documents d'intégration](/fr/integration/onboarding/capabilities-and-requirements#upload-documents).

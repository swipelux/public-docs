Jokainen maksu ulos alkaa valmiista, rahoitetusta luodusta lompakosta. Kohdemalli riippuu siitä, kuka omistaa päätepisteen.

```mermaid
flowchart TD
  A["Funded issued wallet"] --> B{"Who owns the endpoint?"}
  B -->|"Customer"| C["Customer account acc_..."]
  B -->|"Another person or business"| D["Recipient destination dst_..."]
  C --> E["Create quote"]
  D --> E
  E --> F["Execute and track transfer"]
```

## Ennen kuin aloitat

Hae lähdelompakko uudelleen. Vahvista, että sen nykyinen tila sallii maksun ja että sen käytettävissä oleva saldo kattaa aiotun lähdesumman. Tallenna sen vastauksesta johdettu ID muuttujaan `SOURCE_WALLET_ID`.

Tarvitset myös valmiin maksu ulos -kyvyn nykyiselle asiakkaalle ja valitulle kohteelle.

Olemassa olevat Tron-lompakot voivat lähettää USDT:tä toiseen Tron-lompakkoon `stablecoin_transfers`-tarjouksella. Syötteen ja tuotoksen on käytettävä samaa verkkoa ja samaa stablecoinia. Uusia luotuja lompakkoja ei voi luoda Tron-verkkoon.

## 2. Luo maksu ulos -tarjous

Käytä [`POST /v3/quotes`](/api-reference/money-movement/post-v3-quotes) -toimintoa näillä otsakkeilla:

```http
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: payout-quote-001
Content-Type: application/json
```

```json
{
  "customerId": "${CUSTOMER_ID}",
  "capabilityId": "${CAPABILITY_ID}",
  "in": {
    "amount": "150.00",
    "currency": "USDC",
    "accountId": "${SOURCE_WALLET_ID}"
  },
  "destinationId": "${PAYOUT_DESTINATION_ID}",
  "out": {
    "currency": "USD"
  }
}
```

Tallenna `data.id` muuttujaan `QUOTE_ID` ja esitä palautettu hinta ja maksut.

### Valitse pankkireitti {#choose-a-bank-route}

Krypto-fiat-maksussa ulos voit asettaa valinnaisen `institutionId`-arvon edellyttääksesi asiakkaalle hyväksyttyä pankkireittiä. Jätä se pois, jos haluat käyttää automaattista reititystä.

```json
{
  "customerId": "${CUSTOMER_ID}",
  "capabilityId": "${CAPABILITY_ID}",
  "institutionId": "${INSTITUTION_ID}",
  "in": {
    "amount": "150.00",
    "currency": "USDC",
    "accountId": "${SOURCE_WALLET_ID}"
  },
  "destinationId": "${PAYOUT_DESTINATION_ID}",
  "out": {
    "currency": "USD"
  }
}
```

- Nimenomaisesti annettu `institutionId` ei koskaan vaihdu toiseen pankkiin. Kun valitulla pankilla ei ole valmista reittiä tälle asiakkaalle, kyvylle ja kohteelle, `POST /v3/quotes` palauttaa `422` [`bank_not_supported_for_customer`](/integration/errors#bank-not-supported-for-customer) osoittimella `/institutionId`.
- `institutionId` on sallittu vain krypto-fiat-maksu ulos -tarjouksissa. Sen lähettäminen maksun vastaanotto-, kortti- tai stablecoin-siirtotarjouksessa palauttaa `400` [`validation_error`](/integration/errors#validation-error).
- Tarjousten ja siirtojen lukupyynnöt palauttavat valitun reitin `institutionId`-arvon, myös automaattisesti valitun, kun pankki voidaan tunnistaa.

### SWIFT-maksut ulos {#swift-payouts}

Tuotannossa USD-määräiset SWIFT-maksut ulos edellyttävät valmista SWIFT-kykyä, joka tukee maksuja ulos (`swift_pooled` tai `swift_named`), ja ne rahoitetaan USDC:llä Ethereumissa, Basessa tai Polygonissa tai USDT:llä Ethereumissa tai Polygonissa. Vastaanottajan summan maksujen jälkeen on oltava vähintään 100.00 USD.

SWIFT-kohde tarvitsee pankin katuosoitteen kenttiin `bankAddress`, `bankCity`, `bankState` ja `bankPostalCode`. BIC-koodin maan on vastattava pankin maata. Swipelux ottaa edunsaajan osoitteen asiakkaan tai vastaanottajan profiilista.

## 3. Suorita maksu ulos

Luo siirto [`POST /v3/transfers`](/api-reference/money-movement/post-v3-transfers) -toiminnolla. Käytä yhtä uutta avainta tälle aiotulle suoritukselle:

```http
X-API-Key: ${SWIPELUX_API_KEY}
Idempotency-Key: payout-transfer-001
Content-Type: application/json
```

```json
{
  "quoteId": "${QUOTE_ID}"
}
```

Tallenna siirron `data.id` muuttujaan `TRANSFER_ID`. Onnistunut luonti käynnistää maksun; se ei todista toimitusta.

## 4. Seuraa toimitusta

Lue [`GET /v3/transfers/{transferId}`](/api-reference/money-movement/get-v3-transfers-by-transfer-id) luonnin jälkeen ja jokaisen tapahtuman jälkeen. Käytä uusinta `data.state`-, `data.stateDetail`- ja `data.openTaskIds`-arvoa päättääksesi, odottaako, toimiako vai näyttääkö lopullinen tulos.

Seuraavaksi tutustu kohtaan [Tarjoukset ja siirrot](/fi/integration/quotes-and-transfers) tarkkojen summien, turvallisen suoritustoipumisen ja siirtotehtävien osalta.

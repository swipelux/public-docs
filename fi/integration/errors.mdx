description: "Käsittele jokainen julkinen Swipelux API -ongelmakoodi, päätä milloin uudelleenyrittää ja ratkaise validointi-, tila-, idempotenssi- ja alustavirheet."

Swipelux API -virheet käyttävät `application/problem+json`-mediatyyppiä. Haaroita sovelluksesi käyttäytyminen vakaan `code`-arvon perusteella ja käytä sitten alla olevaa toimintoa ja ohjeistusta virheen ratkaisemiseen.

| Kenttä | Käyttö |
| --- | --- |
| `type` | Vakaa dokumentaation URI ongelmakoodille. |
| `title` | Lyhyt ihmisluettava ongelman otsikko. |
| `status` | Tähän vastaukseen liittyvä HTTP-tila. |
| `code` | Vakaa koneluettava arvo sovelluslogiikkaa varten. |
| `detail` | Tilannekohtainen ihmisluettava teksti tälle esiintymälle. Älä jäsennä tai vertaa sitä. |
| `correlationId` | Pyynnön tunniste, joka tallennetaan lokeihin ja liitetään mukaan tukeen otettaessa yhteyttä. |
| `retryable` | Kun `true`, sama pyyntö voi onnistua myöhemmin. Kun `false`, muuta pyyntöä tai täytä edellytys ennen uutta yritystä. |
| `errors[]` | Kenttätason validointitiedot, mukaan lukien JSON Pointer, kun se on saatavilla. |

Uudelleenyritä idempotentit kirjoitukset alkuperäisellä `Idempotency-Key`-avaimella sekä muuttamattomalla menetelmällä, polulla ja rungolla. Älä koskaan käytä samaa avainta uudelleen eri aiottuun toimintoon.

```json
{
  "type": "https://docs.swipelux.com/errors/validation-error",
  "title": "Validation Error",
  "status": 400,
  "code": "validation_error",
  "detail": "The request contains invalid fields.",
  "correlationId": "01JERRORVALIDATION",
  "retryable": false,
  "errors": [
    {
      "pointer": "/externalId",
      "code": "invalid_format",
      "message": "Use a valid external identifier."
    }
  ]
}
```

### `forbidden`

**HTTP-tila:** `403`<br />
**Uudelleenyritettävä:** Ei<br />
**Ongelmatyyppi:** `https://docs.swipelux.com/errors/forbidden`

**Merkitys:** API-avain on kelvollinen, mutta sillä ei ole lupaa suorittaa tätä toimintoa.

**Milloin se ilmenee:** Tunnistetiedolta puuttuu vaadittu käyttöoikeus, tai tuotantotunnistetieto kutsuu vain sandboxille tarkoitettua päätepistettä.

**Mitä tehdä:** Käytä oikean ympäristön tunnistetietoa, jolla on vaaditut käyttöoikeudet. Älä paljasta tai korvaa avaimia asiakaspuolen koodissa.

**Uudelleenyritysohje:** Älä uudelleenyritä muuttamatonta pyyntöä. Toteuta yllä oleva toimenpide ennen uuden pyynnön lähettämistä.

**Asiaankuuluvat API-toiminnot:** Kaikki todennetut API-toiminnot.

### `invalid_field_for_type`

**HTTP-tila:** `400`, `422`<br />
**Uudelleenyritettävä:** Ei palauteta<br />
**Ongelmatyyppi:** `https://docs.swipelux.com/errors/invalid-field-for-type`

**Merkitys:** Pyyntö sisältää kenttiä, jotka eivät ole kelvollisia valitulle resurssityypille.

**Milloin se ilmenee:** Diskriminoitu pyyntö, kuten yksityishenkilö- vastaan yritysprofiili, sisältää toisen muunnelman kenttiä tai jättää pois valitun tyypin vaatimia kenttiä.

**Mitä tehdä:** Käytä valitun tyypin skeemaa, poista muihin muunnelmiin kuuluvat kentät, anna sen vaaditut kentät ja lähetä korjattu pyyntö.

**Uudelleenyritysohje:** Tämä ongelma ei palauta `retryable`-kenttää. Älä oleta, että muuttamaton uudelleenyritys on turvallinen; noudata yllä olevaa toimenpidettä ja toiminnon idempotenssivaatimuksia.

**HTTP-tila:** `413`<br />
